关于果内发酵 Intracellular Fermentation

10月份去宁夏游学时，戴老师给我们讲了葡萄酒里的CM二氧化碳浸渍，但是有点听的半懂不懂的；最近小红书上偶然看到一篇讲葡萄酒酿造里的果内发酵帖子一下子好像理解了： ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

二氧化碳浸渍法是实现果内发酵的一种方法，它涉及到将整粒完好的葡萄浆果在厌氧条件下进行一系列变化，包括酒精、挥发物质的形成，苹果酸的转化，蛋白质、果胶质的水解以及液泡物质的扩散、多酚类物质的溶解等 。在二氧化碳浸渍法中，葡萄浆果与外界二氧化碳交换，一部分被果实中的酶系统利用，合成苹果酸、琥珀酸、氨基酸、糖以及酒精等物质。同时，浆果也释放二氧化碳，这是厌氧条件下果实进行细胞内发酵的结果；


我们尝试过模拟这个过程，冲入二氧化碳，经过3天-14天不同的浸渍时长，确实果子的外观发生了一些变化，确实看得出果皮出现了颜色的变化，时间越长，果皮的颜色越发的暗一些，也开始从很完整的状态变得亮闪闪的再到瘪下去，好像确实类似葡萄的果内发酵，果子内部开始有一些分解，但这种状态下的果子，晾晒完成后喝到的感受最明显的是完全没什么发酵感，更多的是一种清甜的感觉；也没有有辨识度的果香； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

新产季需要做一些调整，可能要借助一部分的CM浸渍之后再换一个方式发酵；

关于乳酸发酵

最近这个例子被我讲了好多次了，去年的这个时候都没有这么直观的理解；

最近去宏丰基地时，吃饭时吃到一碟腌菜好好吃，很酸爽；我就问我们的后勤主管杨姐，这个腌菜怎么做的呀？杨姐说：“ 菜洗好切好，放点盐巴，放点糖，加点水就好了；等菜开始变颜色了，尝一尝就可以吃了 ”；

清洗 - 我们咖啡果也可以做，也在做；
放点盐巴 - 为啥？可能有的朋友在最近两年买到的国外的熟豆上看处理信息会有提到一个信息“鲜果用2%浓度的盐水做清洗浸泡之类的”，跟腌菜的放盐有一个共同的原因，就是用盐去抑制酵母菌，使酵母菌的活性降低，而乳酸菌在低盐浓度下反而会被促进生长，是不是挺神奇的；
放点糖 - 给乳酸菌吃；乳酸菌代谢糖（葡萄糖）产生乳酸； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
放点水 - 我也问杨姐，加水加多少呀，是不是要盖过菜呀；她说是呢，就盖过菜就可以了；-- 要厌氧，因为乳酸菌是一个厌氧菌，它对于氧气含量很敏感，在无氧或者微氧下菜好生存和壮大； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
然后杨姐还说，加温水会发的快一些；哈哈哈哈，温度！这个关键的条件也有了。
然后杨姐还说，这坛子菜吃完了，把汁水拿出来一些发新的一坛会酸的快一些 --- 这不就是Mosto处理么； ‍ ‍ ‍ ‍

我们在咖啡的加工处理里完全可以把腌菜的过程稍微调整下就可以应用过来； ‍ ‍ ‍ ‍
我们巴西的咖农已经在这么做了：

产季初时，庄园主会选一批成熟度好的果子，用盐水6%浓度（狠人）和酒精（10%我记得是，虽然书上说8.5%的酒精度就会抑制很多酵母了）去做两罐子菌种的筛选，分别在室温下和冰箱里冷藏条件下各放置7天； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
