基本信息

国家：埃塞俄比亚 Ethiopia

产区：南部部族州-西达玛-布拉 SNNPR-Sidama-Bura

处理站：卡拉莫 Keramo

村：阿伊萨 Hayisa

贸易决策：尼古思 Niguse Gemeda Mude （对就是那个男人，2020年埃塞首届CoE冠军小农）

品种：74158

海拔：2320 - 2400 米

采收处理：2024.12
空运到港：2025.3

烘焙度：浅度 Light Roasted


// 这两个批次都是各有1袋，估计后面也很难再有了 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


处理方式：日晒 Natural

建议养豆：2周起

风味 ：花香、菠萝、橙子、柚子、桃子 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Floral, Pineapple, Orange, Pomelo, Peach

入口第一感受是非常果汁感，像新鲜成熟的菠萝柚子桃子樱桃一起咬下去的感觉，伴随着花香，酸感很扎实，甜度也能很高，跟我们上一产季（现在还在售）的Agena很像，很扎实的酸，甚至会有一丢丢果醋的感觉，浓度稀释下就会变为很果汁感，整体有点像玛格丽特瑰夏日晒的那种果味特征，低温还会有一些芒果跑出来，哈哈，好喝！


处理方式：水洗 Washed

建议养豆：2周起

风味 ：洋甘菊、黄柠檬、葡萄柚、红布林、梨 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

C hamomile, Lemon, Grapefruit, Red plum, Pear ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

这只水洗好棒！入口就能感受到类似菊花茶和洋甘菊的花茶香气，然后伴随着很爽口黄柠檬和葡萄柚的果酸，果味的部分更多偏向红心的葡萄柚，然后转一些红色核果的果味，特别的透亮，连着喝了几口我觉得好像还有一些青苹果和梨的果味～这才是烘焙后一周的表现，还有一些些许的烘焙感，等再放两周估计就会非常完整和细腻了！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


关于这个批次

这个豆子是我们第四次拿到这个村子出产的咖啡：）还记不记得2020年埃塞的第一次CoE赛事里夺得第一名的Niguse小农呢，没错，他就是来自Hayisa村子滴，2025产季的额第一批空运批次，我们有机会再次拿到Keramo的豆子，而且这次是日晒和水洗同时到了，不过空运批次只有各1袋的配额～

Karamo 与 Keramo ‍ ‍

Niguse建立的贸易公司名字叫做 Karamo Coffee Export ，咖啡来自的村落Keramo，所以我们早名字上做了更新选用了村子的名字Keramo； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

在Karamo Coffee的官网上可以看到有3个处理站，分别是 Hayisha、 Baturtatesa与Keramo； ‍ ‍ ‍
