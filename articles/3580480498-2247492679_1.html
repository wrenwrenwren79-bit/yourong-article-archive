第一次采购，木瓜庄园好多年前就听闻过，一只没有机会接触到，终于如愿以偿；在普洱一个朋友店里喝到了刚烘焙好的水洗，就觉得很干净，莓果和红糖，有点类似哥伦和肯尼亚的味道；后来看到同庄园同品种还有日晒和橡木桶日晒，果断都入了一箱，做了这一期的订阅豆，大家可以横向比较看看他们三个的差异～样本刚烘焙完我感觉日晒最好喝，橡木桶日晒并没有预期的那么的酒桶和发酵，但是放了两天再喝橡木桶的发酵感跑出来了，不是很重的那种，但是很丰富，这三个共同点是都很甜和饱满，也算是给我们机会积累了一个产区的品种品尝经历空白～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于 Hacienda La Papaya ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

木瓜庄园位于厄瓜多尔南部的Saraguro镇旁边，庄园负责人Juan 拥有农学学位；Juan是从2010年开始接触咖啡，虽然庄园已经属于家族很久很久年头；由于曾经有玫瑰种植管理的经验以及有农学学位的专业背景，Juan 以一丝不苟和科学的方法全身心投入到对高品质咖啡的追求中， 他对实验的痴迷和对科学证据的需求是他每个阶段工作的基石，从仔细施用和监测施肥、收获期间不断测量Brix糖度和咖啡鲜果重量、严谨的发酵的创新，到严格的干燥过程；为了更好的与市场对接，以及更多的推广厄瓜多尔小农的咖啡，他创立了一家名为 CaféExporto 的出口公司 。


Typica Mejorada 增强（改良）铁皮卡~
这个是厄瓜多尔近几年很火热的一个品种，与Sidra并驾齐驱横扫厄瓜多尔的咖啡生豆赛事，但据世界咖啡研究中心WCR的基因检测结果，它可能是一个波旁品种与埃塞的某原生品种杂交而得，目前在厄瓜多尔和哥斯达黎加都有种植。

关于橡木桶处理
这个批次的橡木桶处理使用的是厄瓜多尔本国酿制朗姆酒的酒桶，它在处理咖啡前用来陈年朗姆酒二十年了，咖啡鲜果放入橡木桶中静置厌氧发酵，期间橡木桶放置在低温（不高于18摄氏度）的暗房中，发酵5天后取出晒床晾晒； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
