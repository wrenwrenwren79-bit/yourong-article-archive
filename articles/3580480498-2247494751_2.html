5- 晒床干燥，夜间将咖啡果收入袋中过夜

这款瑰夏跟其他几只做过厌氧发酵+热冲击的都有很大的不同，它的发酵感会轻很多；同时能感受到类似于这几个月陆续买到的秘鲁瑰夏和厄瓜多尔瑰夏以及Sidra的那种梨子的清甜，同时又有类似核桃树的那种黄色水果像香蕉苹果一类的香气特征，中温开始会越累越像在云南到处能买到的那种香蕉干（不是冻干的那种，是烘干很有嚼劲的那种）,还有一些轻微香料感； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


处理过程摘录如下：

1- 采收成熟度高的咖啡果 ‍ ‍ ‍ ‍ ‍

2- 鲜果在发酵管里厌氧发酵76小时

3- 发酵结束后，浮选，筛除瑕疵果以及杂质 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

5- 将鲜果放入60摄氏度水中浸没静置24小时

6- 晒棚下干燥10-12天 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

这款辣椒波旁跟以往的都不太一样，以前的都是偏桃子草莓红色的莓果核果类，都是很轻盈的类型，这一款研磨后第一反应闻着发酵感很重，甚至有一些酱香（心里打鼓，完了，现在特别怕酱香）；破渣后赶紧喝了一口，还可以嘛，没有想象中那么重的发酵感，心安了很多；然后温度降一点点后逐渐解开了它的面纱，深色的莓果，果干，有很长一段温区里特别的像也门的炼金术士的那种精品黑巧的气味，然后尾韵的苦甜特别像太妃糖，也是温度越低越好喝～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于Zarza ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Zarza Coffee是由Gasca家族，一个已经3代的咖农家族企业所创立，农场一直以来跟其它咖农一样都是生产大宗的商业咖啡的，直到2012年，第三代接班人Jhonatan参加了SENA开设的一个咖啡培训，第一次接触到有别于传统的加工处理经验以外的处理方式，培训结束后，Jhonatan即刻与父母和叔叔和兄弟们商议，要转变咖啡的生产方式和产品定位，就这样开启了Zarza咖啡的精品之路；（SENA全称是 SERVICIO NACIONAL DE APRENDIZAJE，是哥伦比亚政府劳务部下属的一个公共培训服务机构，提供各类技术和补充课程培训，哥伦比亚很多咖农在SENA开设的各类咖啡专业课程里参与受益，而且它是免费的；我们在售的景秀农场的负责人Edwin就是SENA的讲师，也是CQI认证的Q的处理课讲师）。 ‍ ‍ ‍ ‍ ‍

Zarza的意思是黑莓，当大家一致同意Jhonatan的想法后，需要一个新的名字/品牌来代表大家伙，这个时候Jhonatan的妻子提了一个主意，家族姓氏“Gasca”与黑莓灌木有关，而黑莓灌木的生长习性是它的周边会伴生着其它作物一起生长的，这就好像家族里所有成员的力量团结在一起，大家齐心协力去把咖啡的种植，管理和加工处理，生意都经营好，于是就这样定在了Zarza这个名字。

Zarza Coffee由位于海拔1450米至1800米不同海拔高度的4个家庭农场（LA MARIA、BELLA VISTA、LA PERLA 和 SANTA ANA）组成，其中有帕卡马拉、辣椒波旁、粉波旁、希爪波旁和Wush Wush等品种。农场不断发展壮大，家族也在不断壮大，成为一个欣欣向荣、生机勃勃的地方。
