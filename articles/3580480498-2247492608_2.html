// 瑰夏（一家亲）手冲拼配 ‍‍‍‍‍
手冲拼配是2023年的第四季度我们开始尝试的产品，它的出发点就是希望在溯源和具体的单一品种/产区概念之外有一类新的产品可以让大家能先喝起来，再去想，哎哟，这杯好像还不错，它是个啥？它来自哪里？让好喝带来好奇和兴趣，再带来进一步的探索和尝试，终极目标～那就是你每一天都会想来一杯咖啡，可以一样可以不一样，就是想喝，爱喝！这款全瑰夏手冲拼配很有复合型果汁的感觉，高温入口时很明显的猕猴桃，甜橙，甜感爆炸！中温以后开始转成黄桃和水果硬糖般的甜和一点点的果酸，整体的酸质非常细腻柔和，很顺滑，尾段是水果茶。

// Good Start 2024 开门红新年限定意式拼配
2024就来啦， 开门红！希望我们自己以及所有的朋友们都能有一个好的开局，不过其实这些都是特别虚和精神层面的，不管碰到啥磕绊，怀着一颗不掉肉就不疼的心态，找一个让自己能自洽的状态和角度，翻不过去咱就绕过去，干不翻它咱趾高气扬的忽略它还不行么？
Havea GOOD START 在2024的每一天！YEAH！
说到这款拼配呢，别看组成这么复杂，其实就是把我们觉得一些便红色风味调性的，比如说红色的莓果/核果/柑橘/果干/茶啦枣啦之类的，再做一下小小的筛选（毕竟豆子满足条件的属实还不少），再打了几次样比较测下来确定了这个组成，暂时还不确定是不是会变成常规产品，万一变常规了，那可能就会改名为 美好开局每一天了～
