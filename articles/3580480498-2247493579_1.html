巴拿马 沃肯 詹森 瑰夏 Lot457/523 水洗 2024产季 （¥ 182/100g）

巴拿马 博奎特 唐本杰 瑰夏 Lost Origin 031-056酵母厌氧蜜处理批次 2024产季 （¥ 438.4/100g）

谁说冲动是魔鬼来着～ 这一期里有我们今年买过的最贵的一只豆子，但是它很好喝啊，还是值得冲一冲的！

第一次上豆单的阿尔铁里 ，这只瑰夏水洗批次让我第一反应就是之前黛博拉的Vivid和艾力达的Torre/Loma/Plano的那冲柠檬红茶红糖水般的甜的感觉，传统，饱满！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
詹森是这个产季的第二次采购 了，第一批的批次是这个产季第一批采收的，豆子很新鲜很新鲜，可能静置都不充分，但是当时大家伙都缺新产季豆子，结果还没怎么反应过来就卖完了，这回是产季中的两个批次，我觉得比产季初期的风味强度明显的有增强，它也是一只传统类型的瑰夏水洗，相比阿尔铁里的柠檬红茶感，詹森这一只更偏清新的绿柑橘绿茶调一些，对了，这个产品实际是两个小批次457和523，风味很相近，为了库存卖的久一些，我们把他们合并一起了； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
唐本杰，第二次拿到的Lost Origin处理批次 ，比去年贵了不少，但是开心的是，比去年好喝很多，这个批次的花香茶感，柑橘莓果果香都比去年更清晰，同时酸甜更饱满，整体喝起来会觉得丰富、层次和细腻感要更高一个等级；这个批次拿到资料标题是去果皮日晒发酵，但是看过程是鲜果脱皮后装入发酵罐，然后加入几种不同的酵母进行发酵，所以我就改成了酵母厌氧蜜处理来描述了，这个批次继续有去年批次的Kveik Voss啤酒酵母～这个产季我们在云南也买到了商业用的Kveik Voss和一些其他的不同类型精酿啤酒的酵母做了一些发酵尝试，感受是这些啤酒酵母都会增强最终咖啡的酸甜感，但同时又不会带入很多其他的杂味，咖啡喝起来跟清澈透亮了一些；
