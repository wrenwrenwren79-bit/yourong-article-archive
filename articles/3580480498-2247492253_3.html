处理方式：厌氧水洗 Anaerobic washed ‍ ‍ ‍ ‍ ‍ ‍ ‍

烘焙度：浅度 Light Roasted

风味：茉莉花、甜橙、黄桃、黑莓、伯爵红茶 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Jasmine, Orange, Yellow peach, Blackberry, Earl grey tea-like ‍ ‍ ‍

又是第一次采购和使用的品相，每年都听到詹森的大名，以往都是因为价格原因无法选入，现在俺们也可以稍微用一些比较贵的豆子了哈哈哈哈（自豪自满）；这款也是一款传统处理风格的豆子，虽然它的处理方式是96小时厌氧水洗，但其实现在产区现在在处理第一段对鲜果做一定时间的厌氧又或是有氧发酵已经是非常常见，有点司空见惯的情景了，就拿这款豆子来说，鲜果的前置厌氧带来的是风味里会有更扎实的酸感，可能来自于一部分的乳酸发酵，同时香气也有除了柑橘以外更多层次的核果、莓果特征。

关于詹庄园

詹森庄园的历史可以追溯到1926年，当年仅21岁的 Carl Axel Janson和妻子 Peggy Janson 从瑞典来到巴拿马这块富饶而又原始的土地；随后Carl购置了一个农场用来做乳品生意，从瑞典引入了Brangus牛与一些不同的马种，又从佛罗里达引入了不同的鱼种投入到庄园附近的湖中来打造一个多样多元的农场，这些都展示出了他独到与长远规划的眼光。 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

1980年代中期，家族意识到农场的自然风土条件对于咖啡种植的适宜性，于是开启了咖啡的种植，1990年Carl的儿子（ Ricardo, Carl, Peter and Michael） 接管了农场的业务，成立了Jason Coffee，继续秉承着父亲对于农场生态，对于家族生意以及对于所有产品的品质要求发展下属的所有业务，也是詹森开始进入咖啡领域的开始。 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

30多年过去了，现在庄园有Carl的孙子辈的Kai和Janette以及家族第四代Miguel（Janette的儿子）来管理运营，庄园种植品种有卡杜艾、卡杜拉、帕卡马拉以及瑰夏。 ‍ ‍ ‍ ‍

查资料时，查到农场里有一处设施让我感觉到很温馨和感动，就是给所有工人们提供的小儿子Day Care中心，身为父母（小朋友还年龄较小）的我非常有感触，一个让你放心踏实的托儿所是多么的重要，这里可以让工人们踏实放心的去工作，小孩子在这里有玩了的设施，有老师看管做一些早教工作，真的是超级超级棒！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

除此之外，家族对于环保和生态保护也有自己的一些实践，比如在自己的咖啡店或者农场里使用玻璃器具以及可循环使用的容器避免塑料垃圾的生成；还有一个为了保护附近的原始生态的保育室，由Miguel来负责管理，从农场附近的原始森林里收集一些原生的植株种子在这里保育，同时也开放一部分空间给公众，对于来访的自然爱好者客人们可以从这里拿一些回家自己培养种植；农场的电力主要有400块太阳能板来供给，同时燃烧的燃料也来源于咖啡生产过程中的一些产物比如说羊皮纸。 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


关于这个批次 Lagunas ‍ ‍ ‍ ‍

这个批次来自于农场的一个地块Lagunas，它的名字来源于附近的Lagoon湖与湿地，位于1350 - 1400米的海拔高度。
