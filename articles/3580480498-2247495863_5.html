（2025.11.12)第一批产季报告线下巡游结束了～活动中大家一致对于Lot 179有很高的评价，说喝到了国外瑰夏的感觉，Lot179和Lot177，Lot168这些都是去皮后用了啤酒的酿造方式来做的处理，都用了麦芽粉（热水浸泡，模拟糖化，晾凉后加入咖啡中），还有不同的用了啤酒酵母和啤酒花，目前来看，麦芽粉的水-麦汁是很有帮助的，啤酒酵母和啤酒酒花没有直接的效果；
（2025.8.11) 新产季的水洗和日晒批次即将上线啦，水洗和日晒会先上一个基地的大货批次，挺不错的～
（2025.6.6) 今早继续测试，0420的蜜处理太好喝了，很花香橙子蜂蜜，很细腻，很可能是今年的最强大货批次了；最近也开始测试水洗的批次了Lot4，很扎实的甜，跟去年的批次类似的柠檬红茶感，只是今年的甜更扎实，酸柔和了，入口更柔软更顺一些，也好喝；蜜处理和水洗的批次这个月就会陆续上线了～24产季的批次会轮岗到拼配与挂耳包里消耗； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

‍ ‍ ‍
（2025年5月）产季还没有结束，我们自己的小批次还在陆续晒干测试以及晾晒中，最近测到一个很棒的蜜处理批次，是4月20日晒干收袋的，420正好是浦东店开业的日子，你说巧不巧～非常好喝一个蜜处理批次，虽然它静置的时间有些短，但我还是赶紧盯着老板把它安排脱壳筛选发回上海了，再一次“近水楼台”哈哈哈； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
今年有一些新的收获体会，比如说咖啡果除了外观看起来的“成熟”度，红与不红，全红还是半红等等之外，更重要的是果子的汁水含量，这个在不管经过什么加工处理方式后的最终豆子上体现的非常的整洁，果子如果多汁的，果胶比较粘的，那么最终做什么处理出来的豆子都有基本的酸甜和风味，反之如果果子拨开或者我们习惯咬一颗尝一尝，感觉不到有什么汁水的那大概率出来的豆子都会很寡淡甚至发酵上会很容易出现花豆的风险～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
（2024年6月）这个产季最大的收获是，甜感比去年更扎实了，开始出先一些类似瑰夏村的瑰夏风味了，甚至出现了咖啡花香；豆型上延续去年观察的现象，产季后期豆子颗粒比较大，不过小颗粒的也好喝的～豆子的结构比较完整的也比去年多了很多，密度也比去年有提升。

（2023年6月）这个产季有两个收获，1-芒龙基地的果子大/小颗粒是有风味差异的，地块也是有差异的，但差异的最直接原因是水/肥的差异，而并非海拔高低的差异；2-相比果子大小和地块间的水肥不同带来的差异，更大的差异是果子的成熟时间点，春节前后的早一些时候熟了采收处理的果子相比进入4月后的果子，做出来的豆子简直像两个品种一样，大小，饱满度，以及最终烘焙后的颜值和内在都是进入4月后的要胜出很多，这也给了我们来年的处理思路，在不同的时间点针对果子来做合适的处理产品。

品种：瑰夏 Gesha

处理方式：日晒 Natural

农场/地块：芒龙基地

海拔：1300 - 1400米 masl

批次：Lot176（2025.4.16采收，8月脱壳）

风味：橙子、刺梨、乌梅、红糖和烤红薯甜

Orange, Rosa roxburghii fruit, Dark plum, Brown sugar & Roasted sweet potato sweetness

这个批次是今年比较满意的日晒批次之一，它的处理过程是多段式的晾晒干燥～收储静置结合，基本的节奏是室外晒鹏晾晒2-3天，然后再收回空调房静置2～3天，这样往复操作接近2个月时间达到最周收储的目标含水率；这个操作的目标是希望借助一些发酵/酶促的作用丰富一些香气特别是酸质的层次感，同时又不希望太多，所以室外的晾晒和室内的收袋静置就是一个给前面的过程刹车和一个启动再一次的微生物活动的一个循环～风味上它入口的第一印象是好满足，还扎实，刺梨橙子乌梅带着饱满的红糖和烤红薯的皮的那个焦甜一股脑的冲上来，一定要大口大口的喝～

Red plum, Cranberry, Grapefruit, Cacao, Winy

这个是比175和176批次早三天采收的，然后山上下雨，没办法去运果子下山，于是咖啡果在蛇皮袋里静置了3天，下山后和175，176同一天做的处理，但是打开袋子浮选的时候就能感受到有很多果子已经有那种米酒发酵的香气了，果子的颜色也开始发乌，有一些也由于重力挤压和果内发酵开始破裂出汁水，这个3天的袋内发酵在后面浮选后的相同后置过程里就 呈现出来这三 个批次里更为明显的发酵感，香气特征和味道都开始从柑橘核果 转向核果莓果 到果 干可 可，这三个批次也是这个产季很有记忆点和比较价值的一组～

特征关键词：红色莓果核果+红色柑橘+红酒酸+精品可可（发酵感明显）



品种：瑰夏 Gesha

农场/地块：芒龙基地

海拔：1300 - 1400米 masl

批次：Lot167/168/169/177/179（2025.4.19采收，8月脱壳）

风味：柚子、红布林、甘蔗

Pomelo, Red plum, Sugar cane

特征关键词： 黄色柑橘+红色莓果核果+饱满的甜


这个批次是多个小批次混合成的大批次，它们有用到麦芽，也有用到前面一些发酵批次的啤酒酵母和酒花发酵结束后的Mosto收集二次投入使用，还有一个没有任何外源物质参与的传统处理批次，总的来说，不管是酵母，酒花或者麦芽粉（糖）的参与都会让最终喝到的酸甜感得到不同程度的改善，在入口的酸甜柔顺上以及随着温度变化的酸甜稳定上；

这个批次就得益于麦芽的参与，甜感很明显明确，这种甜感的增益甚至提升了整体的干净度和好喝程度～


品种：瑰夏 Gesha

处理方式：厌氧蜜处理 Anaerobic Honey （处理发酵：老板，后置阴干晾晒：阿梦）

海拔：1300 - 1400米 masl

Floral, Orange, Honey pomelo tea-like, Raspberry

批次：Lot0420 （2025.3 - 4月采收处理，4.20脱壳） ‍

从24产季开始，基地的蜜处理批次越来越稳定啦，今年的几个批次都很稳，机缘巧合给我碰到了这个批次，0420对我们是一个很有意义的数字，尽管据这个批次的数字的编写者阿梦口述，她当时收袋时要给它编一个批次信息就用了当天的日期，一切是那么的随意偶然又很必然，必然的到了我们的产品里～非常的好喝！今年开始新基地投入了使用，有充足的晾晒场地，而且有不同地势带来不同环境温度的晒棚，人力也充足，所以今年的小批次会有经过多段式的收晒以及室外太阳直接照射（刚发酵结束后的头2-3天）-晒棚下（自然晾晒结束后）-空调房（晒到半干具备收袋但不会有发霉风险的阶段），然后反复晒棚晾晒和收袋存放空调房，这种复杂的收晒非常的耗工，但出来的豆子的风味是真的好，特别是酸的质感，层次和强度以及酸到甜的过渡感受比之前的晾晒方式都改善了很多；

这个批次有去年最好喝的蜜处理批次的影子，很甜，干净，入口的酸甜像吃到这边的柑一样，还有一些淡淡的花香，尾韵还有一些树莓的果香感受，相比另外一个啤酒酵母+酒花的厌氧蜜处理批次它的酸的持久感会弱一些，更绿茶感一些～

特征关键词：黄色柑橘+ 红色莓果核果+ 绿茶感

这是扎根在保山多年的守拙农业团队定制处理的批次，该批次的咖啡鲜果来自于佐园芒龙基地，第一次使用了暗房干燥的方式，鲜果采收后厌氧发酵8天，然后沥干，放入暗房内的晒床上，低温环境下干燥2周左右；它的酸感非常的扎实，从热到冷都保持的挺好的，有发酵感，像巴拿马和哥伦的一些偏发酵类型的产品，需要养豆久一些会有很丰富的调性展现出来；

特征关键词 ： 红色莓果+红酒和洛神花茶酸感+精品可可

特征关键词：黄色红色柑橘+红色核果+酸甜明亮+生普清甜

蜜处理是三个批次里最稳定的，稳定的缘由是它有水洗的干净度，又有日晒的果香和饱满的甜感，而且它入口的明亮果酸+香气复合在一起非常直给，中后段能感受像蜂蜜抽子茶泡水的感觉，再喝一口，哇还是甜甜甜！


处理方式：缓慢干燥厌氧日晒 Anaerobic Slow Dried Natural（俺独家产品）

建议养豆：3周

风味： ‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍ 蔓越莓、葡萄柚、红布林、红酒感、可可碎

Cranberry, Grapefruit, Red plum, Winy, Cacao nibs

批次：2024.4-2024.5月采收处理

今年的厌氧日晒有几个不同的批次和加工方式，相比去年发酵成都有所收敛，发酵的时长从1-7天不等，不同的的是今年的批次在缩短单次发酵时长的情况下，调整发酵次数，做了2次和3-5次不同的多重厌氧发酵；将一个长的时间切分成多段的短时长发酵，是从去年的一个批次经验里获得的启发；时间这个变量在冲煮、烘焙和加工处理里有一个共性是随着时间的拉长，越会可能产生不稳定不可控的结果，这个结果往往都是往负面的方向；所以就好比我们会用快冲或者快节奏烘焙一样去处理咖啡的冲煮和烘焙，在加工处理的环节，我们也开始往尽可能减少单次发酵的时长，通过调整过程中的温度和多阶段来调控最终所需要的目标风味，今年的几个实验批次的结果还是不错的；但由于厌氧日晒的生豆需要更久的静置时间，所以这个产品会再晚一点上线~（不过分享包做对比还是可以先来一波的）；

当前我们选择了两个相对还不错的批次做了一个7:3的组合，测了几次还不错哦～入口红色莓果和核果，像蔓越莓和红布林混合果汁，非常顺滑，酸度中等偏高，尾韵有类似葡萄干和轻微可可的感受；


处理方式：Mosto 厌氧日晒实验批次 SG10

Anaerobic Natural with Coffee Mosto SG10（ 处理发酵：祖秀，后置阴干晾晒：阿梦）

批次：2024.4-2024.5月采收处理

建议养豆：3周

风味：乳酪、芝士、橙子、厚实绵密 ‍

Yogurt, Cheeze, Orange, Creamy ‍ ‍ ‍

2021年开始，我们就开始收集咖啡果的发酵液，并尝试保存和培养扩殖；每一年都会尝试一些批次，一直到这个产季开始能确定复制的生产这个风味调性的产品；
它的风味特别是香气的特征特别像一些过桶的葡萄酒或者威士忌里的那个酸酸的奶奶的气味，但是在酒里对于它的接受度也根据酒的类型有不同的阈值，多了就会是一个负面的风味特征；
在咖啡里，我们第一次辨识到这个气味特征特别的兴奋，对于咖啡来说它太特别了，它可以让这只咖啡提升一个非常不同的风味维度，希望大家都能感受到它～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

处理方式：二氧化碳浸渍厌氧日晒实验批次

CM Natural（ 处理发酵：叨叨，后置阴干晾晒：阿梦）

批次：2024.4-2024.5月采收处理

建议养豆：3周

风味：洋甘菊、芦柑、绿茶感 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Chamomile, Mandarin orange, Green tea-like ‍ ‍ ‍ ‍ ‍ ‍ ‍

这个批次是用我们定制的发酵罐发酵的，接了一个外置的二氧化碳生成的气瓶；二氧化碳对于我们来说之前脑海的刻板印象是“它会不会让发酵变得更强；更好；又或者更快？”，但实际使用了几次发现，二氧化碳气的作用正好相反，它是会抑制发酵过程的，它还可以降低发酵环境温度；这两个影响的结果就是咖啡会进行一个非常缓慢的发酵过程，但是完全的厌氧环境又可能会带来类似葡萄酒的二氧化碳浸渍的整串发酵里的果内发酵的进程，只是不知道是因为果子内部糖的差异还是果皮果肉的风味物质元素的差异，结果咖啡的这种复合发酵没有带来很强的发酵感，也没有带来很丰富的水果气息，它带来了很不一样的清甜的味道感受，很干净的清甜～还挺特别的 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于佐园

番啟佐 ，我叫他番大哥，大家也叫他 老番 ， 番佐 ，土生土长保山人，咖三代，为啥呢？因为从爷爷一辈就开始种咖啡，当时是大集体，是给苏联老大哥供应的；到了番大哥父亲一代，开始包产到户了，不过碍于种植面积少就两三亩地，也没能有多大的发展；88年，12岁的番大哥与哥哥一起在保山的新寨种咖啡，也是成家立业在即，在叔叔们的帮助下，番大哥从银行借贷到第一笔资金，在芒柳村的山上开荒，建房，种植咖啡，那一年是1998年，番大哥的儿子文豪也在那一年出生。


咖四代 番文豪 图片是刚读大一 那年假期回来帮忙


芒龙基地是番大哥从2016年开始筹建的新基地，它三面环山，周边植被覆盖丰富，水源也很充足并且干净，相比芒柳基地，这里的海拔高了近400米，气候非常的凉爽，但由于通风与水源的关系，这里冬天并不会结霜，相当于一块天然宝地；在这个基地上，番大哥主力种植瑰夏；2020年算是第一年的产出，当时的产量特别少；我们自己是从2021产季拿到的第一批豆子，我记得当时就只拿到了24kg。 ‍




瑰夏是番大哥在芒柳基地试种了近6年，育种到日常的养护，病虫害等都积累了足够的经验后，才在芒龙开始投产种植，它的品种源自巴拿马的翡翠，今年算是第四年产出，连续的有机肥投入使得今年的豆子比往年更甜更饱满了，当然随着树龄的成长，咖啡树自身从环境里获取营养的能力也一年年的有增强。 ‍‍‍‍‍‍‍‍‍



  • 日晒批次：

    传统日晒处理方式，但是晾晒时是在晒棚下缓慢干燥的，有点类似于阴干，相对的干燥时间较长



  • 厌氧日晒批次：

    今年的厌氧日晒批次没有像往年一样长时间的桶内/袋内静置厌氧发酵，而是分多个阶段，晒-收起厌氧-再晒-再收齐的重复执行带来的余往年一段式长时间厌氧发酵的风味呈现差异～也是我们未来会固定操作的方式，想要发酵感强一些，就收-晒-收的次数多一些，否则就少一些，它相比一段式的静置厌氧方式更为灵活，可控。 ‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍



  • 蜜处理批次：

    鲜果桶中厌氧发酵2-3天后，去皮后在晒棚下晾晒干燥。（天气热就发酵时长短一些，反之亦然） ‍‍



  • 水洗批次：

    鲜果脱皮静置一晚后清水冲洗后转移到晒棚晾晒干燥。



TOP Taste of Process

23产季的处理差异主要体现在水洗，蜜处理，日晒，厌氧日晒在是否有果皮参与发酵，以及发酵的时长和温度带来的风味差异；24产季由于处理方向的整体调整，所有的处理方式都缩短了发酵时长，以及在晾晒环节都采取了相对低温的遮荫干燥，在水洗批次上表现出来的影响特别直接；相对低温的阴干会让酸的质量和强度都有提升，同时一些轻盈的花果香气也会开始显现出来，豆子的结构也会紧实一些；而种植端逐年投入的有机肥和微量元素肥对土壤的改善也开始产生效果了，今年的豆子喝起来我相信喝过的人都能感受到它的甜，这个甜感是完全可以去pk中南美洲很多瑰夏的，特别棒！相信明年会更好！
