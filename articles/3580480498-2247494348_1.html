// 这四个秘鲁是我们在产区测到的豆子预定下来的， 特别的是三个实验批次是咖农，也是我们买到的这些豆子的出口商，他自己的基地里种植的品种，以及他在其它产区学习到的处理经验和购买的处理设备（RF发酵罐就是巴拿马艾力达的手摇式的横向滚筒的不锈钢发酵罐）；
玛格丽塔这个农场也是很传奇的一个生产者，它是由家族里的3个兄弟负责运营，他们是我们目前接触的咖农里最最与当前新媒体时代接轨的咖农，很有前沿的媒体推广意识，同时也有很默契很努力的小团队推进，成果就是在城市端他们有自己品牌的精品咖啡门店，放在任何一个精品咖啡都市不轮从视觉还是产品出品呈现都是顶尖水准的；在种植端他们也有自己的基地和很认真的管理和不断去学习改善的意识，这是我们第一次购买到，大概率未来每年也会持续购买～ ‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍
风味来说，我们最喜欢最惊艳的是赛德鲁小农的厌氧蜜处理，有非常细腻的瑰夏的花果香和果酸，可以pk很多巴拿马的顶尖庄园的产品；玛格丽塔的水洗的酸质酸感更为扎实饱满，特别是它会让你感觉到更饱满的甜；波旁的厌氧日晒大货没有我在产区杯测时测到的那么重的发酵带来的酒感特征，当下它的表现更像是成熟的莓果/核果转向一些热带水果，很干净，可能随着养豆和后面生豆的状态变化会有一些酒感出现； ‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍

埃塞这两个品相是今年第一批到港的25产季豆，跟去年一样，每年到了这个时候就特别的着急，盼着啥时候新产季到货，特别开心，今年俺们的生豆伙伴更给力，更早把新产季搞回来，同时，一样是之前买过的品相，品质也稳稳的～这两只，让我惊喜的是Beloya还是那么的清新，Uraga相比去年的批次没有那么的柠檬红茶，反而变清新了，与Beloya不同的是它的酸甜更扎实，很棒！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Ecuador  Loja Saraguro Hacienda La Papaya Typica Mejorado Natural ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

这两只是来加入凑热闹的编外豆，因为库存都很少，就不会作为正常的产品上架售卖了但是他们都和上面的秘鲁和埃塞新产季有相似的特点；很值得拿来比较着喝，圣塔玛丽亚这只瑰夏水洗是春节前测了几次最终选择的，因为时间关系没有入选到年终总结了，但它可能是我个人整个24年度喝到的最最最好喝的水洗瑰夏，几年前我们曾买到过圣塔玛丽亚的瑰夏，当时是日晒批次，超级的性价比，包装和豆子外观到风味豆特别的棒，去年年中也有机会测到产区来的样本，但是可能之前的预期很高当时就没有选中，一直到年底意外中测到这一只，又找到了那个美好的感觉，当时询问下来生豆的价格已经相比几年前翻了几倍，但最终还是决定买一些吧，好在也只有几kg库存剩余了，就拿了回来囤着看看年后怎么用；同类型的，这只厄瓜多尔的木瓜也是非计划中采购，俺们烘焙师坤坤说南京有木瓜，我们怎么没有测到....于是就在前几天俺索要了样本，今天下午测完一桌子样本决定把它也放进来，命运是如此的相似，它也只有几kg库存了； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
铺垫了这么多，总结下重点，它两入选的原因是：风味属性！圣塔玛丽亚是非常非常细腻的柑橘，它的美好比秘鲁那一只实验批次的厌氧蜜处理更高级；都是我认为瑰夏这个品种风味金字塔顶端的代表； 木瓜的改铁日晒，也是柑橘调，柔顺易饮，甚至能感受到一些橙子和芦柑剥的过程的那种果香，它的酸的持久和层次相比瑰夏是弱一些，但它的特点是甜，是那种喝起来很软没有压力的酸甜； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍



以上8个品相，一共14小包，柑橘和清甜为风味轴，感受下不同的花、果香、果酸的强度，持久度，余韵以及不同程度的植物清香（草本特征），也特别适合这个时节，万物回春的清新宜人；
