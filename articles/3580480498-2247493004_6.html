这两只豆子也是意料之外的产品，当时测到的时候是6月底，在这之前新产季的豆子都已经大部分采购和到港了，拿到他们的样本半信半疑的测了看看，一测发现好意外，怎么到这个时间点了产区还有这么好的豆子么有卖出去，真的是一分价钱一分货，他们的价格在这个产季里算是高的，但它满足了我们选品的两个特殊癖好，1-第一次碰到 2-很好喝，于是就各订了5包；双11前到港，现在总算是可以上线了；
这两款豆子都很“柑橘”，但又有各自不同的侧重点，日晒入口柚子皮般的果香复合青芒，随后转莓果干像葡萄干蓝莓干般的厚实的口感与发酵的果感，余韵部分又有点柚子茶的感觉，整体感觉很“扎实”；而厌氧蜜处理让人有点小惊喜，入口非常的干净，透亮，一下子你就感受到柑橘的水果和果茶的那种细腻的香气和酸质，中间甚至会有一些像百香果的综合热带水果的香气，种低温会感受到西梅和蓝莓的混合莓果感觉，尾韵又很绿茶 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于 Alo与 Tamiru Tadesse

这个批次的生产者和处理站区域也是我们首次采购，它也是来自于Bensa区域，也算是Bombe的友邻，是一个相对较新的咖啡小区Alo村子，是由2021年埃塞Co E的第一名Tamiru Tadesse创立的处理站以及同名的咖啡贸易公司Alo管理运营；


Tamiru是土生土长的Besna人，年轻有远见，从接触咖啡开始到现在也就十来年时间，它看到了所在区域以及周边的咖啡资源潜力，成立Alo公司的第二年便获得了CoE的第一名，随后抓住机会开拓自己的“基地”村寨，即是我们这只豆子的来源Alo村，这里的海拔普遍很高，农户们跟埃塞全国其它的小农一样有祖上分配继承下来的少量土地（2公顷以内），种植咖啡、香蕉和玉米等作物，因为种植的规模小，所产出的咖啡也不足以积聚规模去市场上产品化，加上这个区域一直也没有被人关注，所以尽管咖啡先天条件非常好，但一直被埋没着，果子可能被混入其它Besna的豆子里流通着；直到Tamiru将自己的大本营搬到了这里，通过他积累的一些资本和行业资源开始从0开始梳理这个区域的产销和品质，也就2年时间，已经在国外的很多精品咖啡巨头的产品里出现了Alo的身影， ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于本批次的处理方式
在厌氧发酵蜜处理的过程中，咖农手工采摘下完全成熟的咖啡鲜果，之后运送至ALO咖啡的水洗站，并在门口进行筛选，然后在预清洗之前对咖啡鲜果再次分类，通过观察咖啡鲜果的颜色，来确保鲜果成熟度均匀，再将它们放入塑料桶 中。这样做是为了帮助整个发酵阶段始终保持无氧状态，在那之后去除咖啡鲜果的果皮和果肉。随后，将塑料桶中的咖啡鲜果倒在升高的非洲晒床上，将脱去果皮和果肉的咖啡鲜果薄铺成一层，让发酵汁充分排出。在整个晾晒过程中始终谨慎地将咖啡鲜果铺成薄薄的一层，是为了避免外部微生物活动，因为在此之前咖啡果实已经在桶中进行了必要的发酵。在14-18天后，含水率降到目标水平。
经过厌氧发酵蜜处理之后，咖啡呈现出馥郁的花香和柑橘芳香，与其清甜多汁的风味相得益彰，并伴随有顺滑、清爽的茶感。
