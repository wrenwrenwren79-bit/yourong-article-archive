这是我们的第一次拿到Garrido的豆子，据说这是来自Garrido旗下的Mama Cata农场的（至少箱子上这么写的哈哈），它是一款很经典的传统水洗处理产品，闻和喝都能感受到轻盈的花香，柑橘酸甜果香与柑橘/绿茶复合的感受，甜感很扎实，我相信大部分人都会喜欢他，关键它还不贵！（这只豆子是23产季的哦，新产季的还没到） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于Garrido庄园

加里多庄园的历史可以追溯到1959年，当 Teodoro Garrido开启了家族的第一个农场；1997年，现任的Garrido掌舵人， Jose David Garrido Perez ，买入了Mama Cata农场（前任农场主的名字），在农场原有种植铁皮卡的基础上，Jose将Gesha引入到Mama Cata种植，并用GPS定位每一个地块，来每年跟踪管理每个地块的基础气候，土壤和种植与风味信息等，Mama Cata也成为了Garrido家族里zui优质瑰夏的种植基地。 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
