Lavender, Cranberry, Red plum ‍ ‍ ‍ ‍ ‍

这是棕榈树的瑰夏第三个产季了，这个批次的瑰夏跟去年不一样咯，去年是比较偏香茅，今年是偏紫色的花类的香气，我的第一反应是特别像宜家的一些紫色干花，庄园给它的定义名字是薰衣草，我们就用它来打头作风味描述部分；它入口有很上扬明亮的酸质，高温到中高温从柑橘到红色莓果，一直到低温都酸质都能很明显的感到；这也是今年庄园的所有单品批次与去年最大的改善就是酸质和触感都做的更饱满扎实了； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


品种：粉波旁 Pink Bourbon

采收处理：2024.6 ‍

到港日期：2025.3

处理方式：日晒 Natural

烘焙度：浅度 Light Roasted

风味：洋甘菊、红苹果、柚子茶 ‍ ‍ ‍ ‍ ‍ ‍

Chamomile, Red apple, Pomelo tea-like ‍ ‍‍

产区每一年都会有各种各样的变动，上一个产季，庄园负责人之一的Elisa主导推动了一个妇女项目，项目的主旨是为了感谢和有一些实际的回馈给每个产季参与到生产中的妇女工人们，她们的工作从种植管理、施肥到采摘都有很大的贡献；但是第二年，因为劳动市场的变化，一些原来来打工的妇女找到了更好的工作机会，于是也就无法延续这个项目；另外，加上产季气候的变化，这一批次的豆子颗粒都比较小一些，不过最最最让我欣慰的是它的风味还是很不错滴～它依旧是很干净很清甜，这也是第一次喝到棕榈树的粉波的惊讶的地方，它没有哥伦的那种重的红色莓果甚至会容易发酵往番茄酱转的特征，棕榈树的粉波就很清新轻盈，今年还有一个很大的不同是酸质和触感更扎实了，更柑橘了一些；

今年的黄玉是比较传统的处理方式，仅仅做了一些些轻微的发酵，它没有去年的那么的香茅草的气味了，今年的特征是饱满，圆润，入口特别像成熟的西梅和芦柑的圆润和甜感，然后从入口到吞咽都会有一个糖类的甜香气伴随着，中低温时还有点像烤红薯的甜，今年的这只感觉在拼配里会非常的好用～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍



关于 Fazenda Guariroba 棕榈树庄园

图片来自BSCA - 棕榈树位于数字8的区域 Campo das Vertentes（米纳斯州南部）


Campo das Vertentes并非一个行政划分下的州单位，它是咖啡产区概念上的一个区域，并且2020年获得了巴西国家工业机构颁发的产区地理标识，San Antonio do Amparo 是 Campo das Vertentes这个“产区”下的一个行政市。

早在19世纪，创始人João Ferreira Carneiro就已经在Santo Antônio do Amparo肥沃的土地上生产咖啡，它就是今天的Fazenda Guariroba的前身，对改良咖啡的痴迷和渴望也代代相传下来。
Gabriel Lamounier Vieira（庄园现在主要的负责人）

霍梅罗Homero Aguiar Paiva，一位土木工程师和家族的第五代传人，在2009年从他的叔叔Fernando Paiva那里获得了历史悠久的百年庄园Fazenda Cachoeira的一部分，继续种植咖啡。在他的兄弟雷纳托·派瓦(Renato Paiva)的指导下，霍梅罗选择了较好的品种开始种植，并将这片土地命名为棕榈树庄园(Guariroba Farm)，以纪念他的外祖父母。从那时起，追求卓越和保存最纯净的传统成为该农场的口号，优越的风土条件和家族的丰富知识使Homero Paiva在专业咖啡生产方面取得了卓越的成就，其中就包括2016年巴西卓越杯竞赛的日晒组第一名。
现在，庄园由Homero和他的妹妹和妹夫Gabriel Lamounier Vieira 和 Elisa Paiva Lamounier共同拥有，所有的生产管理由医学背景出身的Gabriel来统筹，包括各种定向菌种发酵的探索，结合有氧和厌氧/二氧化碳浸渍/酒花浸渍等等，以及新品种的选择和种植管理。

关于Catuai-Mundo Novo-Topazio

Catuai - 卡杜艾，在当地Tupi部族语言里是“very good”的意思，它是黄色卡杜拉Caturra（代号IAC 476-11）与新世界Mundo Novo (代号374-19）于1949年在巴西圣保罗的科研中心IAC，人工将其杂交选育出来的，1972年开始在巴西商业种植推广。

Mundo Novo - 新世界，它是在巴西本土咖啡田里由波旁和苏门答腊种（从印尼引种来的）自然杂交而来的一个新品种，它有较高的树形，果实非常的紧密结实，树体强壮，非常的抗风，在巴西占据了近40%的种植，产量和杯品豆较高，相较其它品种会晚熟一些。
Topazio - 黄玉，巴西咖啡研究中心于上世纪60年代到70年代间，将新世界Mundo Novo品种与红卡杜艾结合再与卡杜艾回交的一个人工选育品种，它具有卡杜艾的矮树种特征，果实成熟后是黄色果实，成熟期和一致性都介于卡杜艾和新世界品种之间。
