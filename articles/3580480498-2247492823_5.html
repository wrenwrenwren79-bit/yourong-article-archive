也门是非常非常古老的一个产区，在最初接触咖啡时我们可能被告知或者认为咖啡是来自于也门，到后来才了解到阿拉比卡咖啡从埃塞发源，经由战争传播到也门，然后随着战争殖民以及宗教传播再从也门传到欧洲（早期的上流社会咖啡馆饮用文化）以及亚洲（种子传播）等等，可能是因为这个地域的人文和国情原因，自然条件相对匮乏，相比其它农产品，咖啡的种植生产和咖啡贸易并无法带来持续的很高的收益，我们在市场上很少见到也门咖啡的身影，特别是精品咖啡文化浪潮席卷的早几年，精品/精致的也门更是稀有，又或者价格非常的高昂；一直到最近几年，借由特定的社会资源（QIMA）的运营推广才得以使得也门这个咖啡“老家伙”重批战袍进入我们的视野，而我们也有机会开始选到性价很好的豆子，下面我们来回顾下曾经售卖/在售卖/即将上线的几只也门，跟大家说下这几只的选品动机和我们现在对于也门产区的了解～
卢瓦德小农 也门妮娅品种 传统日晒（已售罄） ‍
Yemen-Sana‘a-Hayma Kharijiya-Bait Alal-Al Ruwad Cooperative，它是我们选的第一支也门，非常经典和有代表的椰枣香气特征，或者也像西北地区的沙枣，就是那种干旱地区出产的甜度高的枣（干）的气味，味道上酸甜很均衡，甜感会比酸感更明显，经常喝浅焙的人可能会觉得它一点也不酸～它来自于Sana'a省的海玛大区下的Bait Alal村里的鲁瓦德小农合作社，是一个集体批次；



巴尼奥费尔小农 也门妮娅品种 炼金术士厌氧日晒（已售罄）
Yemen-Dhamar-Ans-Bani Ofair，这是我们的第二支也门，也是选到的第一支炼金术士处理方式的豆子，它的椰枣风味就弱化很多，由于处理方式带来的厌氧发酵过程使得最终的豆子出现很浓郁的酒感，可可感和类似精品巧克力复合特征，可能得益于咖啡果较高的成熟度或者可能果皮果肉果胶里积聚的糖类物质丰富，经过不同压力的二氧化碳厌氧发酵后带来了这种酒香可可和莓果莓果干甚至会有花香和蜂蜜甜香的复杂香气～它是来自于达玛尔省Dhamar的Ans区下的Bani Ofair村，位于萨纳省Sana'a下方，也是一个村落的集体批次～



约瑟夫鲁玛伊姆小农竞拍批次 也门妮娅 传统日晒（在售，即将售罄）
Yemen-Sana‘a-Hayma Kharijiya-Bait Alal-Yusuf Rumaim，这款是我们的第三支也门，也是第一支竞拍批次，它是一只传统日晒批次，与前面两只相比又有不同的风味，有椰枣但又没那么的椰枣，有类似埃塞的柑橘，又有类似卢旺达布隆迪的莓果，还会有一些类似香料香草的植物香气，有时我又觉得它像东北的菇娘果和贵阳的刺梨，我最最最惊艳的一次是在云南冲了一杯养了快一个月的批次，那个细腻有层次的小酸甜别提多舒服了，那一刻我我觉得它比很多很多瑰夏都要好喝；它与鲁瓦德小农来自同一个村子（Bait Alal村，位于Sanna省），区别是它是来自单一小农家的批次，鲁瓦德是来自于合作社集体的批次；



巴尼奥费尔小农 肯特品种 炼金术士厌氧日晒 XI 批次（即将上线）
巴尼奥费尔小农 肯特品种 炼金术士厌氧日晒 XV批次 （即将上线）
Yemen-Dhamar-Ans-Bani Ofair，这两只也都是来自于Bani Ofair村落，与之前的批次不同的是他们是Kent品种，也从今年的批次开始我们发现了一个新的信息，炼金术士有了不同的批次，比如说这里的XI和XV，他们对应的在处理上的差异是：XI是鲜果浮选装罐后打入二氧化碳一直到最多近10个psi（根据实际的批次会有不同）然后开始静置厌氧发酵，而XV是打入相比XI没那么充分的气量情况下，当然压力也会相应的小很多开始厌氧发酵，也可能还有一些少量的空气残留在开始阶段，这两种方式下，最终的风味在这两只豆子上会有很明显的不同，XI批次特别的葡萄甜酒，精品巧克力，樱桃的感觉，在中温区的单一产区黑巧克力更为突出，到低温时会有一些花香和蜂蜜甜香出现；XV批次就特别的葡萄干，也会有精品巧克力的酸感和可可发酵风味，还会有红色深色莓果的特征，酸感会更强一些酸质也扎实；



鲁瓦德小农 也门妮娅品种 炼金术士厌氧日晒 XI批次 （即将上线）
Yemen-Sana‘a-Hayma Kharijiya-Bait Alal-Al Ruwad Cooperative，这个同样是XI的炼金术士批次，但不确定是不是因为品种的差异又或者是二氧化碳浸渍程度（充入的气量）的差异，它的发酵感比肯特那只XI批次弱一些，同时也能感受到椰枣和葡萄干，果酸上更偏柑橘类，整体很均衡，低温时也会有可可调，也会出现蜂蜜甜香，可能四只豆子里我反而会更喜欢这一只的均衡感，什么都有又什么都不过～



巴尼纳西米小农 也门妮娅品种 炼金术士厌氧日晒 XI批次 （即将上线）
Yemen-Sana‘a-Haraaz-Bani Nahimi, 这是一个新的小农，也是来自于萨纳省，但是是与海玛不同的大区哈拉兹，印象中它是我好多年前最初喝到的也门豆子的区域，依稀记得Haraaz这个区域名字；查资料发现它也可能是也门最为古老的咖啡种植区，可以追溯到4-6世纪，巴尼纳西尼村子里有大概35-40户咖农家庭，种植面积从1000棵树到5000颗树不等，按照云南的精品品种种植来说可能就是相当于十来亩地到40亩之间（100-150棵/亩）～这个批次虽然是炼金术士处理，但是它的风味喝起来依然是很传统的也门日晒的椰枣风味，与传统日晒的椰枣调性不同的地方可能是你能在这里感受到那种牛奶巧克力（40-60%的牛奶巧克力），低温特别的舒适，相比其他3只不同的发酵感，它又是另外一番面貌～



关于也门的品种
大概十年前，是我第一次接触也门的豆子，那个时候记忆里没有什么品种信息，多是以所来自的小区域为名字记忆这款豆子，比如说玛塔莉，哈拉兹，可能唯一跟品种有关的就是也门摩卡，但其实当时那款豆子也不是摩卡品种，更多的是以那个时候的贸易里行销也门的豆子给了一个摩卡的名字，它更像是描述的是摩卡港口，相似的还有巴西的桑托斯等等。




再一次见到也门豆，见到品种信息是2018年底，那一年也是我们第一次接触QIMA，一家目前市场上对也门产区最为了解和投入最多的精力推广的咖啡品牌，当时第一次看到每一支咖啡豆上有它的生产者的信息，他的家庭介绍，他的照片以及不同的品种名称，比如说有Udaini, Jaadi, Tufahi, Dawairi等等很绕口都不知道怎么拼读但又充满了神秘感的名字
“Family is everything”让我特别感动
2020年，由Lavazza，RD2 Vision和QIMA共同成立了一个也门咖啡品种调研的项目，针对也门境内种植的咖啡品种做了一次大摸底，第一次发现并提出也门种植的品种里有一部分是有别于现今世界上其他产区（包括埃塞）的基因谱系，并且将他们命名为New-Yemen既Yemenia家族；
关于处理方式
最初接触咖啡时，从书本和网络上以及听到的是也门的咖啡都是在树上干燥的，因为气候干旱，所以产季时果子成熟后在树上会一直到成干果然后再采收下来，当时就在想，那是个啥画面，直到有机会去到产区，看到果子在树上的实际情况和采收处理晾晒的过程，大概才会觉得之前的那种说法好像没那么靠谱，如果是干果的话，大概率是果子/咖啡树遭受了什么病虫害或者霜冻，导致果子无法完成正常成熟的过程，就逐渐变成干果了，这些干果通常都是不怎么好的果子，里面的咖啡豆本身也不会好；
现在，从最新获得的产区资料里，我们知道也门虽然气候干旱，水资源匮乏，但是果子还是可以自然成熟到红果状态，再人工采收下来的，但因为大部分地区水源不丰富，所以也没有水洗处理或者蜜处理的加工方式，全部是日晒或者厌氧日晒的方式，就那我们上面介绍的7款也门来说，其中有，
  • 传统日晒，鲜果采收后，运送到晒床进行自然晾晒
  • 深度日晒，鲜果采收后，运送到晒床进行晾晒，相比自然晾晒，果子铺晒的厚度翻倍，过程中仔细控制翻晒频次，让果子缓慢干燥（30天以上）
  • 炼金术士厌氧日晒，鲜果采收后，浮选筛除一些瑕疵果和杂质，然后装入不锈钢发酵罐中，充入二氧化碳，然后咖啡果就进入一个二氧化碳浸渍的厌氧发酵过程；其中根据充入的二氧化碳的多少又有XI，XII和XV的批次区分（XI是充入大量的二氧化碳，最高可达到10psi；XII是完全不充入二氧化碳；XV是充入一定量/少量二氧化碳；发酵结束晾晒时，不同的批次也会有铺晒的厚度不同来再次调控发酵的风味差异，比如说XI的批次里果子铺的厚度比较薄，翻晒的频率比较高；XV的批次果子铺晒的厚度比较厚，翻晒频次低，让其能再晾晒时在下层的果子能继续有一些发酵进行
最后，为什么选这几只也门？ ‍ ‍
从价格上来说，也门依旧是比较贵的一个产区，但是了解了它的生产种植情况，它的产量，以及它非常独特的风味谱系，我觉得现在的价格还是合理的（可以买一买的）；为什么一下子选了4只，原因很简单，就是有机会接触到这么多不同的也门，我们自己也通过他们对也门，对其下面的几个大区，品种和处理方式有了新的一些认识，这是乃大一直以来选豆子的很“冲动/随性“的性格：好奇，尝新；可能冲动中也会带一些理性的思考，比如也会考虑性价比和转化，所以也有一个采购的价格尺度，初期采购量会少买一些，看看客人对它的接受情况，再看后面是否再补库存（如果还有的补的话） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
