关于Milan庄园

// 文字来源于Amativo公众号

Milán农场，位于哥伦比亚Risaralda Pereira里萨拉尔达佩雷拉 ，种植面积200公顷。种植的品种有：
Gesha 、Red Bourbon 、Yellow Bourbon 、Pink bourbon、Bourbon Tekisic 、Bourbon Sidra 、Striped Bourbon、 Tabi、Java 、SL 28 、 Catiope 、Sudan Rumé、Moka 、Laurina 、 Yirgacheffe 、Maragogype 、 Caturra 、 Purple caturra 、 Castillo 、Colombia。
由于气候变化，这个地区的咖啡生产变得非常困难，昆虫的繁殖，丰收时又缺工人。目前，生产商的处境都非常艰难，但我们一直在创新，寻找研发更好的加工方式来满足市场需求。因为我们不能失去作为咖啡生产商的核心。我会用我的一生，一直在这里继续咖啡种植和生产。
Milan与小溪 La Riviera属于一个公司旗下，他们还有一个烘焙品牌叫做Cafe Uba，办公室和烘焙工厂位于佩雷拉市区。

这里会发展成一个集合的加工处理中心
现在这里只能进行湿处理，而干处理是在不同的地方进行的，我们规划6个月后，开始解决这个问题。
我们需要选用品质好的咖啡鲜果再进行菌种混合发酵
对于要进行菌种发酵处理的批次，我们会先利用机器把咖啡樱桃按密度分开，做糖度测试，进行不同的品质区分，选择符合发酵需求的咖啡鲜果，再进行脱果皮。将使用采收前培养好的菌基和这些脱皮后的咖啡果「带着果胶的羊皮纸豆」一起混合发酵。

在进行混合发酵的过程里，我需要加入新鲜的水果（通常先榨成果泥）来满足发酵过程里对营养物的需求。当然，这种水果的添加，不一定完全指向性，比如，我加入的是菠萝，但出来的风味主调可能是椰子，而我其实并没有加椰子。


关于处理过程 Nitro - 氮气浸渍：

为了进行氮气发酵，Andres开发了这个发酵容器。这个容器，对咖啡发酵很有帮助，首先，这种材质更容易清洗，可以对这种容器消毒后再进行发酵。另外这个容器上面有一个阀门，可以通过阀门来改变气压。

注入氮气以后，基本每隔3、4个小时，都需要通过取样来检测发酵环境的变化：如温度的变化、糖度的变化、pH值的变化等。通过取样来了解发酵参数是否达标；如果不达标，就需要停止发酵。

大概每隔20-25个小时进行气压调整，因为要保持一个较低的发酵温度，当温度变高时，通过氮气压的调整，可以让温度降下去。

在实际值已经超出了预设定值时，就需要拨开泡沫层，将咖啡豆倒出来了，然后转移至晒场干燥。

//氮气冲刷厌氧水洗，这个批次是采用了类似西瓜系列的氮气冲刷方式，产品的动机是做一款能增强瑰夏品种水洗处理方式下的香气和酸质的细腻层次感的赛级豆需求而来，处理过程简要如下

1. 咖啡樱桃的采收过程是全手工的，并只采摘刚好成熟的豆子（brix > 18）
2. 采收下来的咖啡樱桃会经过浮选，以及浮选后会人工筛选一次，以保证所有进入处理过程的果子品质达标。
3. 鲜果装入塑料发酵桶，有氧发酵10-12小时，期间果子的温度会因为内部的发酵开始而上升；
4. 将鲜果倒入到8-10摄氏度的水箱里降温冷却，这样做的意图是让咖啡豆（种子）里的胚芽调动它的生物活性来为后面的氮气冲刷发酵过程做好准备；
5. 脱皮， 随后，带着果胶的豆子装在塑料发酵桶中有氧发酵10-12小时，然后将其转到不锈钢发酵桶中，加入活化好的酵母发酵液，并充入氮气，期间监控pH，温度和压力来多次注入氮气做搅拌式的冲刷，总过程4-6天之间完成所需的发酵环节； ‍ ‍ ‍ ‍ ‍ ‍
6.发酵结束后，取出豆子做简单的清洗，然后在晒棚里薄铺，自然晾晒15-20天后收储静置30天； ‍ ‍ ‍ ‍ ‍ ‍

//氮气冲刷，桃子和莓果共同发酵厌氧水洗，这个批次是做一款突出白色粉色花香的豆子，复合着不错的果酸，整体丰富有层次；这个批次的处理过程也是沿用了西瓜系列的方式，只是它更为复杂一些，采用了2段式不同水果的浸渍与氮气冲刷过程； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

1. 咖啡樱桃的采收过程是全手工的，并只采摘刚好成熟的豆子（brix > 18）
2. 采收下来的咖啡樱桃会经过浮选，以及浮选后会人工筛选一次，以保证所有进入处理过程的果子品质达标。
3. 鲜果装入塑料发酵桶，有氧发酵10-12小时，期间果子的温度会因为内部的发酵开始而上升；
4. 将鲜果倒入到8-10摄氏度的水箱里降温冷却，这样做的意图是让咖啡豆（种子）里的胚芽调动它的生物活性来为后面的氮气冲刷发酵过程做好准备；
5. 脱皮后将 带着果胶的豆子装在塑料发酵桶中有氧发酵10-12小时，然后将其转到不锈钢发酵桶中，加入活化好的酵母发酵液，桃子汁，并充入氮气，期间监控pH，温度和压力来多次注入氮气做搅拌式的冲刷，发酵5天； ‍ ‍ ‍ ‍
6.随后，将豆子取出简单清洗下，然后转入另外一个不锈钢发酵罐中，类似步骤5的方式加入新的酵母发酵液，并加入莓果果汁，然后冲入氮气，监控做多次冲刷，发酵6天； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
7.结束上述过程后，取出豆子做简单的清洗，然后在晒棚里薄铺，自然晾晒15-20天后收储静置30天；
