这款豆子作为我们第一款 “眼见为实”系列的产品，我们亲自在产区求证了它的处理方式，将所获的资料如实的传递出来； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
使用水果和香料浸渍做发酵已经不是什么新奇绝活了，经过这些年的探索和实践，产区已经有了一套自己的“技术”经验，怎样的品种，怎样的水果（或者冻干水果）以怎样的形态，结合什么酵母在怎样的环境条件下发酵多长时间，这些都已经逐渐的被梳理清晰，就如这款豆子，最初的原型是单纯用肉桂皮或者肉桂粉加入到日晒或者蜜处理中做浸渍处理，但是早期的产品风味的强度和稳定性会在每个批次或者不同的生产者之间会有表大的差异，当人们对与发酵的理解更清楚时，也对风味的完整性更重视时，就开始加入水果和酵母，来得到不同强度的香气特征以及酸质和酸感，配合一定强度的肉桂香料特征最终得到一款有着柔和/温暖/水果肉桂甜香气的产品，肉桂的香料气息在菠萝和柑橘水果的衬托下显得那么的和谐。 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于La Cumparsita ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

La Cumparsita位于卡尔达斯的Chinchina市的 El Bajo Español小镇，庄园诞生于2022年，由Sebastian Velasquez和他的父亲Carlos Velasquez为了家族的咖啡梦想所创立，种植面积5公倾，庄园种植有8个咖啡品种；Cumparsita是一个非常有代表性的小农家庭，基本所有的运营管理农务都由家里的成员，Sebastian的父母和妻子与他自己四人负责，产季时会请一些附近的一些女性村名帮忙；庄园的名字是由Sebastian的奶奶起的，受他的爷爷年轻时经常往来于南美，对跟踪南美音乐的喜爱也影响了他的奶奶，于是当家里想为这个充满了梦想和爱的农场起名字时，奶奶就把很喜欢的一个音乐名字赋予了它； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


关于这个批次的处理方式

这个批次使用了自制发酵液Culturing的方式，使用新鲜的菠萝与肉桂皮，打碎后结合酿酒酵母混合后发酵培养菌群，随后参与咖啡鲜果和脱皮后的两段式厌氧发酵 ‍ ‍ ‍

  • 鲜果采收后浮选，漂出浮果和杂质后，再由人工手选

  • 手选后的果子在不锈钢罐里，加入预先准备的发酵液（酵母+菠萝+肉桂混合）厌氧发酵5天，

  • 第一个发酵阶段结束后，咖啡果脱皮，同样加入发酵液再一起厌氧发酵2天

  • 发酵结束后，取出咖啡豆在晒棚下晾晒缓慢干燥
