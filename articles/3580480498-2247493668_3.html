基本信息

国家： 巴拿马 Panama

产区： 波奎特 Boquete, Chiriqui

区域： Potrerillo Arriba

庄园/处理厂：考托瓦-女巫农场 Kotowa Las Brujas ‍ ‍ ‍ ‍ ‍ ‍ ‍

种植品种：Gesha, Catuai, Caturra, Pacamara, Ethiopians

主人： Ricardo Koyner（第三代）

品种：瑰夏 Gesha ‍ ‍ ‍ ‍ ‍

海拔： 1750 米

烘焙度： 浅度 Light Roasted

采收：2024.1-2月

到港：2024.7月 ‍ ‍ ‍ ‍ ‍ ‍


批次：Lot 2156

处理方式：低温 日晒 Low temp Natural ‍ ‍ ‍ ‍

建议养豆：2周起 ‍ ‍

风味：葡萄柚、蔓越莓、菠萝、红布林、蓝莓干、葡萄干

Grapefruit, Cranberry, Pineapple, Red plum, Dried blueberry, Raisin ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

2156批次的处理操作很复杂，我理解下来过程是： ‍ ‍ ‍ ‍

1- 暗房内晒床上干燥6天（环境：湿度30%，温度18c） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

2- 室外晒床上自然晾晒7天，每天翻动2次 ‍ ‍ ‍ ‍ ‍ ‍

3- 袋子内厌氧低温静置19天（环境温度：19c） ‍

4- 机械干燥（35c）3天 ‍

5- 袋内收储静置 ‍ ‍

喝起来，它是3个批次里发酵带来的酒感最明显的，但又不是特别重发酵那种，入口很快会转化出来葡萄柚和红色莓果和核果的果香果酸，酸质是那种波浪形持续刺激你的那种～中温开始特别的菠萝，那种成熟的菠萝从冰箱里冰镇过拿出来吃起来的果香和酸甜,然后同时还有像蓝莓干和提子干（我脑袋里出现的是那种很长很大的提子干吃起来有点点齁甜的那种） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

批次：Lot 2094 ‍ ‍ ‍

处理方式：缓慢干燥日晒 Slow Dried Natural ‍

建议养豆：2周起

风味：蔓越莓、红布林，樱桃、葡萄干、果汁感

Cranberry, Red plum, Cherry, Raisin, Juicy ‍ ‍ ‍

这个批次喝起来感觉是2156的减弱发酵版本，它没有那么明显的酒感发酵感，入口就是很莓果核果，很果之感，很爽口～中温开始也会出现类似2156的葡萄干的那种发酵感和齁甜 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

处理过程：

1- 鲜果在室外晒床上，薄铺5cm不超过5cm厚度，黑布遮盖2天后 ‍ ‍

2- 鲜果室外晒床上自然晾晒，铺层改为15cm厚度，晾晒11天，每天翻动2次 ‍ ‍ ‍ ‍ ‍ ‍

3- 鲜果收到袋子中静置一天 ‍ ‍ ‍ ‍ ‍ ‍

4- 机械干燥3天（35c） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

5- 收储静置

批次：Lot 2330

处理方式：缓慢干燥日晒 Slow Dried Natural

建议养豆：2周起

风味：黄柠檬、葡萄柚、树莓、樱桃

Lemon, Grapefruit, Raspberry, Cherry ‍ ‍ ‍ ‍ ‍

这个批次喝起来是3个批次里最像水洗处理调性的，入口是类似水洗处理的柑橘果香果酸，像黄柠檬，青柠过渡到红色的葡萄柚的感受；中温开始出现类似其他批次的莓果核果感，也会有樱桃和树莓的风味出来～随着温度降低，会有一些类似葡萄干和提子干的尾韵；

处理过程：

1- 鲜果室外晒床上厚铺15cm厚度，黑布遮盖3天

2- 鲜果保持厚铺15cm厚度，自然晾晒5天，每天翻动3次

3- 鲜果改为5cm厚度，自然晾晒7天，每天翻动2次

4- 鲜果转移到袋子中，低温静置4天

5- 机械干燥1天（35c）

6- 收储静置

总结：2156与2330有相似的酸质感受，特别是在中低温时，他们两的酸的层次延展性都很好，持久度都比2094要长，这一点可能得益于有一部分时长的低温过程；2094和2330从处理上直观的差异是两个阶段铺晒的厚度，按理说厚堆的发酵感应该更多一些，但喝起来反而并没有，可能的原因是在机械干燥的阶段，你会发现2094用了3天时间，而2330只用了1天，那么就是2094再最后一个阶段干燥前的含水率是相比2330更高的，而在更大量的一个堆叠干燥环境里，较多的时长机械干燥其实也可以想象成一个继续相对高温的发酵过程，所以结果就会让2094喝起来有类似2156的发酵感（同样的最后阶段的机械干燥时长和温度设定）～这一组对比还蛮有趣的，能喝到低温和机械干燥对发酵风味的影响 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


关于Kotowa与Duncan

Kotowa在当地Ngobe语言里是山脉的意思，而Duncan是来自于一个加拿大人Alexander Duncan MacIntyre的名字。

Alexander在加拿大的一份报纸上看到在巴拿马，有一个非常原始的山区叫做波奎特，连绵的山峰与火山，这份对未知的好奇心让他第一次踏上了这块土地，当地原始的生态与热情的人们让他彻彻底底的爱上了这块地方。

1918年，Alex在这块土地上定居下来，开始进行农作开荒； 四代人的繁衍生息，现如今，Duncan家族建立的Kotowa咖啡旗下有7个咖啡庄园，分别是
