埃塞 Yaye 厌氧水洗 / 日晒 手冲 / 埃塞 Yaye 水洗 SOE

今年的Yaye还是很稳，厌氧水洗 太好喝啦 虽然小贵一些，但风味强度超扎实！日晒 太好喝啦 比往年要惊喜，特别饱满的香气和果汁感；常规水洗批次相比厌氧微批次要弱一些些，我们用它来做SOE～ ‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍

埃塞 Alo 96小时厌氧日晒

这款Alo也是来自于主站，它就是复制Alo当年拿CoE第一名的处理方式，没有近年出现的复杂的Mosto或者Cascara加入发酵，只是在鲜果保障质量的情况下，做96小时的简单静置厌氧发酵；可以与另外一只ALO Mosto批次做对比； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

埃塞Gotiti 厌氧日晒

这一只预计是双11第二波上线，是最近测试了几轮选中的一只，每年在接近年底即将迎来新一产季的采收处理时刻我们还会淘到一些很优质的当季豆；这一只Gotiti的发酵感特别像之前售卖过的Neguise小农批次，在高温区会有百香果的果香风味特征，酸甜感很橙子，触感也很饱满厚实，中温开始突然会摇身一变像前几天用过的Adorsi厌氧日晒批次的草莓果香，好特别的一只豆子～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


哥斯达黎加 雪松 瑰夏 蜜处理/ 日晒 / 水洗 ‍‍‍‍‍‍

这是第一次采购的农场，也是CoE榜上常客，蜜处理 太好喝啦 批次是我的最爱！酸酸甜甜好舒服～ ‍‍


秋季拼配 浅焙/深焙

今年的秋拼浅焙是第一次以品种为主题主导的产品，风味次之，相比春季和夏季，秋季的浅焙风味特征，特别是在烘焙后2周内会比较没那么“招摇”，再多放1周后就开始逐渐发力；深焙版本是才推出的，它没有用全部的黄色品种，用了40%左右其它的有风味特征品种，去平衡产品定价和风味差异的双重指标；‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍


肯尼亚 ，会有4款肯尼亚在双11第二波上线，分别是每年能买到都会买的Muchagara，Gachatha，还有去年卖过的Embu地区同一个合作社下面不同的处理厂Ndunduri；还有我们年初的第一支新产季肯尼亚Ichamama的水洗要返场啦～


巴拿马 ，巴拿马今年选了好多，特别是Pacamara 太好喝啦 ，最近上了的桑托斯庄园的Pacamara厌氧水洗，是一款有点瑰夏类的柑橘调的Pacamara；接下来还会上一个同庄园的厌氧日晒批次，好丰富好棒；可以跟在售的另外巴拿马达玛莉的厌氧日晒批次做对比，他们分别用了不同的酵母参与发酵～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

巴拿马的瑰夏这一期订阅里的桑托斯的厌氧日晒批次，还有哈特曼的水洗，极光的日晒，极光子庄园灵魂农场的瑰夏水洗也都很有各自的特点 ；

//特别推荐区
哥伦比亚 巨石 瑰夏 蜜处理 24产季 & 瑰夏 蜜处理 23产季 CoE批次
哥伦比亚 巨石 黄波旁 蜜处理 24产季
巨石是去年发现的宝藏农场，蜜处理好强，不论是瑰夏还是黄波旁，酸质都超棒，干净，甜感饱满，酸的质量可以让咖啡整体喝起来的层次感提升好多；因为24产季的瑰夏蜜处理到货了，就把23产季的CoE批次下架了，但最近几次定制生产里再跟踪测试23产季的批次发现它的状态超级好，风味强度和酸质甚至比24产季的都要好（ 太 好 喝 了！ ），所以这次双11，我们将它特别返场，额外新增了一个23&24产季的瑰夏蜜处理组合给有兴趣去对比尝试的朋友； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


也门 ，我们在售的有3只也门，库存都不多了，分别是卢瓦德小农，马扎儿小农和萨纳夫小农；他们都 太 好 喝 了！ ，很有代表性，特别是这个月刚测完也门竞拍的批次以及竞拍的价格后，越发觉得手头的这些大货实在是优秀～ ‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍


埃塞，ToH#1日晒 ，最早的一只高价埃塞豆，也是我们在售的除瑰夏村之外最贵的一只埃塞，超级稳，虽然到港后不到一个月就开始受ALO等优等生的追击，出现过一阵子的低迷市场，客人翻它牌子的次数越来越少，但是它一直还是那么的稳，就在刚才的一轮当日生产批次的测试中它以细腻润无声之资，犹如清风拂面般的舒爽让我一下子惊到了～ 太 好 喝 了！ ‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍‍
