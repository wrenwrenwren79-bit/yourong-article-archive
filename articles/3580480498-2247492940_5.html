Passionfruit, Water melon, Peach, Strawberry, Guava, Pineapple
这就是一个水果炸弹，入口就是各种甜美的果香充盈着，但它又是很自然的，它不像是那种果缤纷饮料里的那种超浓郁香气的刺激，而更像是很多新鲜的成熟的水果摆在面前，你走近它的过程中从远而近能分别闻到辨识出的各种香气，味道层面的酸甜感也很舒服，触感也很顺滑饱满，与丰富的果香很和谐的融合在一起，是一款非常棒的产品～哈哈哈-得意！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

产品动机
这是我们今年第一年从Milan采购这么多款风味具象和每款都很特别的水果浸渍定向发酵类型的产品，采购时的动机非常明确，就是想跟上国外产区的步伐，通过高频的使用和对比（还有其他生产者的同类型咖啡在采购列表中）来感受这类咖啡每一个批次/产季的迭代更新，可能是品种（发酵底物）的更新，可能是发酵环境/发酵液/水果这个组合的不同，可能是发酵过程（有氧与厌氧的组合分配，是否杀菌，温度的不同阶段控制，发酵结束的清洗等）的管理不同，以及最终晾晒过程的管理，所有这些的差异带来每一个批次/产品的特征差异，我们自己可以学习到很多生产的思路与逻辑，从而更好的去传递着部分信息给消费端来，同时也可以调整尝试应用在云南产区以及国外其他合作的产区的生产端去验证和迭代出更好的产品




关于Milan庄园

// 文字来源于Amativo公众号

Milán农场，位于哥伦比亚Risaralda Pereira里萨拉尔达佩雷拉 ，种植面积200公顷。种植的品种有：
Gesha 、Red Bourbon 、Yellow Bourbon 、Pink bourbon、Bourbon Tekisic 、Bourbon Sidra 、Striped Bourbon、 Tabi、Java 、SL 28 、 Catiope 、Sudan Rumé、Moka 、Laurina 、 Yirgacheffe 、Maragogype 、 Caturra 、 Purple caturra 、 Castillo 、Colombia。
由于气候变化，这个地区的咖啡生产变得非常困难，昆虫的繁殖，丰收时又缺工人。目前，生产商的处境都非常艰难，但我们一直在创新，寻找研发更好的加工方式来满足市场需求。因为我们不能失去作为咖啡生产商的核心。我会用我的一生，一直在这里继续咖啡种植和生产。
Milan与小溪 La Riviera属于一个公司旗下，他们还有一个烘焙品牌叫做Cafe Uba，办公室和烘焙工厂位于佩雷拉市区。 ‍ ‍ ‍ ‍ ‍ ‍ ‍

这里会发展成一个集合的加工处理中心
现在这里只能进行湿处理，而干处理是在不同的地方进行的，我们规划6个月后，开始解决这个问题。
我们需要选用品质好的咖啡鲜果再进行菌种混合发酵
对于要进行菌种发酵处理的批次，我们会先利用机器把咖啡樱桃按密度分开，做糖度测试，进行不同的品质区分，选择符合发酵需求的咖啡鲜果，再进行脱果皮。将使用采收前培养好的菌基和这些脱皮后的咖啡果「带着果胶的羊皮纸豆」一起混合发酵。

在进行混合发酵的过程里，我需要加入新鲜的水果（通常先榨成果泥）来满足发酵过程里对营养物的需求。当然，这种水果的添加，不一定完全指向性，比如，我加入的是菠萝，但出来的风味主调可能是椰子，而我其实并没有加椰子。


关于本批次处理过程（分系列介绍）：

//Maypop - 菠萝百香果浸渍

1. 咖啡樱桃的采收过程是全手工的，并只采摘刚好成熟的豆子（brix > 18）
2. 采收下来的咖啡樱桃会经过浮选，以及浮选后会人工筛选一次，以保证所有进入处理过程的果子品质达标；然后鲜果会做8-12个小时的静置有氧发酵（开放的环境中） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
3. 鲜果脱皮后装入发酵罐，同时将新鲜的菠萝和百香果打成浆状加入到发酵罐中 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
4. 活化咖啡的酵母发酵液，静置半小时左右观察酵母活化状态再加入到发酵罐中与先前的咖啡豆与菠萝果浆搅拌混合，密封 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
6.厌氧发酵6-8天 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


//April - 杏桃菠萝二氧化碳浸渍

1. 咖啡樱桃的采收过程是全手工的，并只采摘刚好成熟的豆子（brix > 18）
2. 采收下来的咖啡樱桃会经过浮选，以及浮选后会人工筛选一次，以保证所有进入处理过程的果子品质达标。
3. 鲜果脱皮后装入塑料发酵桶，有氧发酵10-12小时；
4. 随后，带着果胶的豆子被转到一个不锈钢发酵罐中，加入活化好的酵母发酵液，杏桃和菠萝的果浆，搅拌混合，并充入二氧化碳，密封静置厌氧发酵2天 ‍ ‍
5.自然晾晒15-20天后收储精致30天。

//Toffee - 香蕉浸渍

1. 咖啡樱桃的采收过程是全手工的，并只采摘刚好成熟的豆子（brix > 18）
2. 采收下来的咖啡樱桃会经过浮选，以及浮选后会人工筛选一次，以保证所有进入处理过程的果子品质达标。
3. 鲜果脱皮后装入发酵罐，同时将新鲜的香蕉打成浆状加入到发酵罐中
4. 活化咖啡的酵母发酵液，静置半小时左右观察酵母活化状态再加入到发酵罐中与先前的咖啡豆与香蕉果浆搅拌混合，密封
6.厌氧发酵5-6天

//Nitro - 西瓜氮气浸渍

1. 咖啡樱桃的采收过程是全手工的，并只采摘刚好成熟的豆子（brix > 18）
2. 采收下来的咖啡樱桃会经过浮选，以及浮选后会人工筛选一次，以保证所有进入处理过程的果子品质达标。
3. 鲜果装入塑料发酵桶，有氧发酵10-12小时，然后脱皮
4. 随后，带着果胶的豆子装在塑料发酵桶中有氧发酵10-12小时，然后将其转到不锈钢发酵桶中，加入活化好的酵母发酵液，西瓜汁，并充入氮气，静置厌氧发酵4-6天
5.自然晾晒15-20天后收储静置30天。 ‍ ‍ ‍
