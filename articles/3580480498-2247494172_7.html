基本信息
国家：埃塞俄比亚 Ethiopia
产区：西达玛-阿比高娜 Sidama- Arbegona (Arbigona）
庄园/处理厂：波切萨 Bochessa
拥有者：Asefa Dukamo Korma ‍ ‍ ‍ ‍
品种：74158 ‍ ‍ ‍
海拔：1920 - 2330 米
采收处理：2024/1
空运到港：2024/4 ‍
烘焙度：浅度 Light Roasted
建议养豆：2-3周
风味（水洗）：黄柠檬、沃柑、柚子、红茶感 ‍ ‍
Lemon, Mandarin, Pomelo, Black tea-like
这是一只被人雪藏的豆子，被俺们无意中挖掘到了，是这个产季最早一批空运到港的豆子，状态超好！好经典的柠檬红茶调，中间有类似沃柑和柚子的酸甜，它的苦都特别像柚子和红茶的苦，很醇厚，好喝！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

风味（厌氧日晒）：番石榴、菠萝、橙子、柚子 ‍
Guava, Pineapple, Orange, Pomelo ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
厌氧日晒这只很干净，它的发酵感有点类似我们在售卖的Bench Maji3天的厌氧日晒批次，但是Bochessa更偏热带水果一些，入口时番石榴和菠萝和柑橘一起来的感觉，甚至我觉得也有点百香果和猕猴桃，非常柔和的酸甜，特别是甜感很饱满，像咬了一口果肉的感觉，酸酸甜甜～干净，好喝！


关于Bochesa ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
第一次采购到Bochessa，这只豆子来自俺们的好朋友PiggyBank的扛总亲自在产区一嘴喝中的一个批次，我都能脑补那个画面，一个咖啡人在产区喝到一只很棒的豆子，然后促成了一个连接，这也是我的咖啡梦最初开始的方式，也是在发生在埃塞； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
产区，当你亲自经历这些的时候，那个时刻的触动是会铭记的； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Bochessa跟Rumudamo一样都属于Arbegona区域下，豆子的风味调性也非常的相似，很经典的柠檬红茶，酸甜也很饱满～它也会成为我们来年重点关注的一个处理站哈哈哈～感谢扛霸子。 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
