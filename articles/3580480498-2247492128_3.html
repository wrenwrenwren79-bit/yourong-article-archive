接上回 - 我们来到了Manizales

深夜到的，一路上我们经过了两个小城镇，有种很奇妙的感觉 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

感觉到了越来越生活化，越来越“正常”的生活，虽然也有摩托车，也有汽车，也有行人 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

但感觉大家的状态没有麦德林没有Cali那么的急躁～很奇妙 ‍ ‍ ‍

路上Jairo说现在看不清了，白天的话能看到路两边很多咖啡树，这里也是一个咖啡重镇 ‍ ‍ ‍ ‍ ‍ ‍ ‍

隔天是周日，终于又可以休息放松下了 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

上午不用起那么早，到鲜农办公室杯测已经10点多了

体验了哥伦本国的一个烘焙机品牌的样本烘焙机型号，在这边很普及，几乎每个农场的样本烘焙机如果有的话都是这个牌子的，做工和性价比都很好，没有外置显示曲线过程，只能靠一个温度表头和通过看、闻、听来判断，回到了原来的那个年代，但是因为样本都是很好的豆子，实在有点担心别烘废了，

第一锅强烈要求旁边的老手带一炉，后面烘了5锅，还行哈哈，有点意犹未尽～

测到两只风味很明确的豆子，都是来自La Cumprisita的（后面会上这个农场的豆子） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Seb和他的太太，好年轻的一对咖农，办公室见到Seb比照片瘦了不少哈哈哈 ‍

这是La Cumparsita的Red Fruit处理，用覆盆子和酿酒酵母以及咖啡的发酵液（mossto）做的混合浸渍发酵，未来会有机会喝到 ‍ ‍ ‍ ‍ ‍

庄园主Sebastian很年轻，他们家种植咖啡也有20多年了，一开始是在Chinchina种植水果在当地卖水果，后来加入了咖啡， Sebastian 接棒后，学习种植，学习加工处理，和Diviso，Nogales类似都是新一代的咖农，加工处理上也有自己的Technics，再次的，我表达了我们在消费端客人和烘焙商，每每碰到这些风味很具象的豆子的怀疑和顾虑，我们需要详细的处理方式信息，如果加了什么东西，也要说出来，这些信息都需要从生产端经由贸易传递到烘焙商和终端消费者，烘焙商可以选择用或不用，客人可以选择买或不买，他非常理解也很同意，没有像其它人那样有“商业秘密”的顾虑，后来鲜农的同事拿出笔记本给我看了一个他们接收到每个样本的记录表格，里面是有我们想了解看到的内容部分的，只是信息的传递到末端有缺失，我开玩笑说，下次你们发这些资料给国内同事时，请给我一份原版的，我想学习西语用～哈哈哈哈，说实话，通过感兴趣的部分来了解和学习一个新的语言特别有乐趣也有成就感，这一程我学会了拉瓦都，拿图啦，号尼，扣三岔，搜卡，包撒，林匹亚，度c，包了哇否昂定抵扣，瓜头洒牛斯~

这种冰激淋摊位有估计二十来个 ‍ ‍ ‍

测完豆子，还有小半天时间就去感受了一把当地人们周日的休闲活动，到了一个广场，路两侧都是小摊，很多卖冰激淋的，煎饼的（arepa，不是我们山东杂粮煎饼那种），烤肠（chorizo），当然还有很多咖啡摊，看到一个Willys的小卡车，后面车斗里放的是咖啡设备，乍一看我以为是一个老式的意式咖啡机，那种靠热水蒸气压力来萃取的，像个小锅炉的样子，但后来他们说那个是保温的，咖啡都是做好的放里面，再仔细看其它的摊位好像大家都是差不多类型的只是有大有小，都是直接放咖啡出来～果断放弃，但这个小吉普是真的帅呀，在Huila那边是雪弗莱的Tropper比较多，这里就是吉普的Willys特别常见，而且这些都是二三十年的老龄车了，还是拉人拉货翻山越岭，那么能抗，甚至还有人改装柴油成天然气～牛！

我犹豫了下还是没有买，拍照留念 ‍

这个特别特别好吃，在第一周去Felipe家路上吃过一次，当时我还有点恐甜有点克制，这回在Manisales我可不要克制了，而且这边还有加炼乳～赞 ‍ ‍ ‍ ‍ ‍ ‍ ‍

广场尽头有一个纪念第一批来这个城市开拓的人们，雕像做的特别的形象很有故事画面感，回去我要读一下历史补一补课 ‍ ‍ ‍ ‍ ‍

正好日落，刚拍完这张照片没过两分钟就开始下雨了 ‍ ‍ ‍ ‍ ‍ ‍ ‍

周一，这一天简直是疯狂、震撼，直到晚上躺到床上都让我在回忆这一天发生的事情；

一大早离开Manizales, bye ,天气不错哦

早晨六点半开拔，一出收费站，Jairo就笑着挥手说，“Byebye Manisales”，一下子有点小不舍；来的时候是晚上啥也没看清，这下子看到了，好多好多咖啡树，从收费站一直到Chinchina一路两边都是咖啡树，而我们要去的Pereira更是历史上这边的咖啡三角（Quindio, Risaralda, Caldas的枢纽），它很早就收益于咖啡经济带来的收益，所以城镇的基础设施都很好，很好的公路，以及一些集中的消费区域，餐厅也会有一些国外风格融合的类型；今天我们安排是El Placer上午，下午去Campos Hermos（我当时是没有任何概念这是哪里），晚上去El Milan（这个是王老师出来前跟我提了很多次的，当时我还想行程上不一定有）； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


Brocca 咖啡甲虫会从果子一端钻进去留下一个黑点 ‍ ‍

虫子钻进去的位置，里面的果皮和羊皮纸壳外面也有一个黑点 ‍ ‍ ‍ ‍ ‍

正好有咖农老爷爷在栽种小苗～看到他每一颗小苗周边一定范围内都手工拔草清理的干干净净 ‍

对于成年树苗，Seb说他们也是人工拔草的，原因是地表有很多咖啡的地表根系，如果机械除草容易伤到，大家的农艺操作经验都不同 ‍ ‍ ‍ ‍ ‍

晒场故意做成不同的格子区块来晾晒不同的批次，会有一个牌子标记信息 ‍ ‍ ‍ ‍ ‍

处理设施区域也是有不同的颜色和标记来做功能区块和操作指引的划分，甚至在处理站外面和仓库等都有类似的设计

结果呢，El Placer被 Sebastian（对，也叫 Sebastian 哈哈） 拉着农场里溜达回到处理站，再讲解完处理过程已经中午了，然后先吃饭吧～吃饭的地方太美了，对着远方的美景，面前熏着咖啡香（驱蚊的），吃着好吃的食物，SUPER！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

吃饭的地方特别的赏心悦目～望着对面的开阔风景，好美呀


杯测本来是传统处理和微生物发酵以及添加处理各几种，然后再次聊到我们市场端的疑虑，然后又打开了话匣子，然后又多了5杯咖啡，是他的标志水果系列，有Green , Red, Yellow, Purple和一个新的Mojito（偏香料），在这里我也了解到了，水果系列里面有不同的水果，Lulo，草莓，百香果，菠萝，莓果，以及风味糖浆，在 能获取到冻干形态的水果产品条件下就会选用冻干的水果产品然后再磨碎使用 和La Cumpristia的相似产品来比较的话，有没有糖浆或者说糖的多少会直接影响到了最终风味里香气-酸质，整体风味从热到冷的融合和稳定，再结合我们两年前在云南尝试的水果浸渍，我们当时的结果就是能喝到微弱的香气，但是很不稳定，消散很快，原因可能有两个：1-我们的水果没有打的很碎，量不够多 2-我们的糖不够多，给酵母代谢的食物不够（而这里有一部分原因跟1也有关，如果不把水果打的很碎的话，也不利于水果自身的糖类物质被微生菌那么容易获取到或者获取的效率会很低），风味糖浆的选用也是和水果是相同调性的，目的也是可以让香气增强，当然还需要添加酵母～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

六个不同的水果和香料系列

在El Placer感受到了另外的不同，除了感受到了他对市场端产品喜好的关注和琢磨，也感受到了他对加工处理过程的谨慎，不管是发酵，脱皮和晾晒，他都在“管控”过程和批次的一致性； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

正巧碰到一个墙绘艺术家在现场绘画，特别的漂亮 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

离开El Placer已经快5点了，下一站是Campo Hermoso，对于这个名字我是没啥印象了，Mateo也是第一次开车来这边，开过去的时候路线还有点难找，然后Mateo就说，我们迟了，但是我们约好的，还是要来看看，心里带着一些歉意到了农场，然后到了就看到两桌豆子已经都称好在桌子上了（原来是3桌的，因为时间关系...），进去打招呼认识了Edwin和他的品控助手和烘焙师Ana，然后Edwin就开始带着我们开始看加工处理的场地和讲解过程（我也不知道为啥直接上来就讲这个，忘记了是我问了问题打乱了他的节奏还是因为天开始黑了，有点晚了，去地里也不合适），但是接下来的半小时让我要骂娘了，现在想起来都还能感受到那个时刻的惊讶和感恩，故事是这样的，Edwin带我们先去实验室看了下他们在做的事情的方式，讲着讲着，我看到一包大概5kg装的铝膜袋的东西（其实我脑袋里第一反应是很邪恶的，我想着这个不会是那个啥啥啥XJ吧）然后我就很装着很自然的靠近它拿起来看看，然后看到一个小贴纸上写着Hops，再看其他信息哦是Cascade Hops，然后我就说哦，这个是酒花呀，Edwin说是的是卡斯卡特酒花，他们会有一类产品使用酒花，因为我们刚好最近到了巴西的一只酒花处理的产品，用的是Galaxy Hops，我就顺嘴提了起来，我都没有提庄园，我只说是一只巴西的豆子用的Galaxy Hops，他手托着下巴看着前面停顿了几秒种，然后转过来说是不是Guiroaba？ ， 我当时就WHAT？我说是的，但是你咋知道的，然后更妙的是接下来，他说因为是我教他们做的.....我当时脑到里就骂娘了，嘴上差一点，WT。。。the F words almost ,然后心里就有很多很多问题，感觉情绪就好像大海起了浪一样一波波的翻涌着，克制着激动，继续听他讲，然后他开始讲了他的经历，从2014年开始就和棕榈树合作，他也是CQI和SENA的讲师会开一些加工处理课程，他也很早在哥斯达黎加/墨西哥做加工处理顾问给一些农场和公司做处理方式的研发，然后这两年给瑰夏村也有远程支持过一些加工处理方案，然后聊着聊着我知道了Saturio，我们的仓库里还有4箱豆子是Saturio的，他给我门看了一些他在哥斯达黎加和墨西哥的加工处理的照片，我甚至觉得，我门在用的哥斯达黎加和曾经用过的墨西哥，都是出自他之手或者跟他有关，这个世界好小，好小～然后一下子可能气氛太嗨了，他又带着我们讲解了更多的处理过程，大家都忘记了还有两桌豆子等着要杯测，看到烘焙师小姑娘在旁边站着才想起来，赶紧去杯测～

第一轮测完，中场休息看到外面已经起雾了，体感明显感觉到清冷了，这个是这边的常态，这个季节经常这样，多么特别的微气候呀～ ‍ ‍ ‍ ‍ ‍ ‍ ‍

她是用这个烘的样本，超级棒，超级干净，很柔软，很透 ‍ ‍ ‍

杯测中两桌豆子都特别精彩，有两只和我们仓库里的两只特别像，我感觉应该都是同一个产品，但是这里就超级干净和细腻，整体喝起来就让你觉得好舒服，好柔软，Mateo也有同感就问Edwin是有什么改变吗今年的处理，感觉干净度和平衡感都提升了很多，Edwin笑笑说，今年的产品批次在发酵结束后都做了水洗，往年的带着一些果胶的晾晒会有不稳定～喝到一只超级喜欢的非常非常蜂蜜的豆子，希望能买得到哈哈哈～还有，Ana豆子烘的好好，香气味道触感都很有，最重要是很干净，SUPER！


完美的一天～Perfecto

这一天我还又收到了礼物，哈哈，然后鲜农的最后一站我们的Jairo同志突然身体不适，去医院折腾了一个下午，一路辛苦他了 ‍ ‍ ‍

全是跟咖啡有关的哈哈～而且这瓶350ml的酒哥伦国内航班是可以带上飞机的，都没人查 ‍
