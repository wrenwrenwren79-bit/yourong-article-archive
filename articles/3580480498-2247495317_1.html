这里再发一些当下行程中用到的豆子和一些处理的目的：

卡蒂姆/萨奇姆组 8
  • 卡蒂姆 暗房日晒 Lot52（不再和反复收晒混合使用了，单独拆分出来），这个批次的目的是让大家来感受下暗房日晒对于一个常规的卡蒂姆有什么改变（可能是很有限的）
  • 卡蒂姆 厌氧日晒 葡萄酒桶内静置发酵 Lot 1/7/9
  • 卡蒂姆 厌氧日晒 柠檬，酵母参与发酵 Lot 28/48/49
  • 卡蒂姆/萨奇姆 厌氧日晒后 热冲击 Lot 182/183
// 上面四个日晒可以对照着感受下在这个品种，日晒处理上我们可以容易操作的几种方式的发酵能带来的风味差异和可取之处；

  • 卡蒂姆 厌氧蜜处理 发酵过程中加入透气（氧化）过程 Lot 10
  • 卡蒂姆 厌氧蜜处理 瑰夏和铁皮卡果皮培养的Mosto参与发酵 Lot 11/33
  • 卡蒂姆 厌氧蜜处理 自然霉变 Lot TP07
  • 卡蒂姆/萨奇姆 厌氧水洗 （鲜果脱皮后简单的做了一些段时间发酵然后清洗果胶晾晒）Lot BSW
// 这三个蜜处理批次，前两个也是容易操作和复制的方式，可以调整酸感酸质，而第三个是老天爷赏脸给了一个新的线索，是下一个产季的工作重点，它让我们喝到了一些被争议的哥伦的豆子的 风味特征，但是完全自然发酵的；第四个水洗是简单的发酵后清洗果胶晾晒，是高海拔的卡蒂姆/萨奇姆的品种特征；

瑰夏组（低海拔/高海拔）12
瑰夏 低海拔 厌氧蜜处理 发酵过程加入透气（氧化）过程 Lot 70/71/73
瑰夏 低海拔 厌氧蜜处理 酵母参与发酵 Lot 72/74
瑰夏 低海拔 日晒 Lot 75/78
瑰夏 低海拔 厌氧日晒 多次收晒方式 GoY #12
//这四个批次是同一批鲜果，分了蜜处理和日晒两组做了9个批次，最终筛选合并成了4个批次；蜜处理是测试了类似卡蒂姆组的增加透气氧化来通过加大醋酸菌的影响来改变最终的酸质呈现，日晒测试了分阶段的收-晒来调整干燥节奏和在不同的含水率下收储起来后再次启动的微生物活动（aka发酵）来带来的不同发酵感的风味差异，最终我们可以有机会得到更加微调的果感和酵感的平衡；

瑰夏 高海拔 日晒 GoY #14
瑰夏 高海拔 厌氧日晒 酵母参与发酵 Lot 120/121/125
// 这两个批次是来自于最新的一块基地的第一个产季的果子，真正的baby瑰夏，它让我们终于这么多年后开始有信心云南是可以种出来瑰夏样子的瑰夏的，豆形饱满漂亮，滋味也还可以～哈哈哈

瑰夏 高海拔 日晒 红果 Lot 175（成熟度正常）
瑰夏 高海拔 日晒 紫果 Lot 176（成熟度高）
瑰夏 高海拔 厌氧日晒 紫果 Lot 169（预发酵3天）
//这三个批次是对照组，来自同一基地，175和176同一天采收，但是成熟度不同；169是更早3天采收，但是下雨没办法下山就只好山上袋子里捂了3天，都是好喝的，特点不同；

瑰夏 高海拔 厌氧蜜处理 麦汁参与发酵 Lot 167
瑰夏 高海拔 厌氧蜜处理 麦汁和啤酒酵母参与发酵 Lot 168
瑰夏 高海拔 厌氧蜜处理 麦汁和啤酒酒花参与发酵 Lot 179 （这个真好喝，以至于做一场活动生豆就卖掉几kg，现在俺只剩下年终总结的了）
//与上面3个日晒来自同一基地，今年是第二年开始尝试用啤酒酵母，也是第一次开始用酿啤酒的方式去套用到咖啡的发酵过程中，虽然我的麦芽糖化还比较粗暴，留待下一个产季去精进了～他们三个在前面的线下活动中一致被大家肯定，说喝到了中南美洲瑰夏的味道～
非常希望能有更多的咖啡朋友们参与到这个活动里来，大家抓紧对着各自城市的时间场次报名吧～
