这个水洗批次和上次三个日晒批次一样都是那个男人（Nigusse）选品的优质批次，关于这只咖啡是到底来自于哪里我纠结了一晚上，因为测样和麻袋信息是Arbegona，但是Nigusse的资料和原话是它来自于Morke村，还解释了当地有一条很有名的河流Logita是穿过Morke，Argegona和Tatesa，地图上我没有找到这条河，也没有找到Tatesa，不过大概定位了下Morke，Arbegona和Bura的一些地点位置，大概率咖啡是来自于他们中间的交叉地带； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

风味上，这一只豆子类似Rumudamo和Danche水洗，也有青提和芒果的风味特征，酸质特别的明亮，而且酸感和触感都很饱满，豆子颗粒和上色也都很均匀～是一只好豆子，单品和未来会出一个Arbegona/Sidma的拼配都会用到它； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

可以留意下耶加的区域是在上图的左下角从Wenago开始往南到Tore之间都是我们常会碰到的各种耶加雪菲；在Bura的右边深绿色区域有一个Nansebo它旁边就是Nensebo就是我们曾经卖过的West Arsi区域了；右下角Adola也是曾经卖过的它属于Guji；地图上没有进来的是在左边更远更远的地方一直像西就会到Bench Maji区域； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
