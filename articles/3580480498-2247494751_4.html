‍ ‍
这支黄帕的风味调性介于我们之前买的巴拿马桑托斯的帕卡玛拉水洗和即将售卖的哥伦未来的帕卡玛拉水洗之间，它有柑橘和莓果调性，也有一些些香料感；特别需要提的是处理方式，在哥伦我们在很多咖农提交的豆子信息里都看到“半水洗”的品类，比如说我们售卖的绿宝石粉波蜜处理，那后来为什么我们售卖产品时将其改名为蜜处理了呢？如果我们看处理方式过程，鲜果脱皮后进入一个不同时间的发酵环节，然后发酵结束后会做冲洗，这个就类似一个常规的水洗处理过程，差别是如果传统水洗的定义是脱皮后发酵充分后，用水清洗掉全部的果胶，而这里的“半水洗”咖农的操作是用少量的水简单的冲洗一下，所以结果就是还有一些果胶残留附着在咖啡豆（羊皮纸Parchment）上，而有果胶附着的状态其实又像是蜜处理的情况，类似于“白蜜”类型的产品，我们就基于有果胶残留进入干燥的阶段的原因将其还是命名为蜜处理；这里发酵结束后清洗的动作在我们曾经多次喝到的国外的豆子和我们自己的实验批次来看，清洗果胶有两个好处：1-晾晒时会翻晒更方便管理操作，不会跟晒床/晒网有风险粘连到一起，豆子之间粘连的几率也会变低，这样就会避免一些晾晒不均匀风味差异，甚至严重的时候因为翻动不及时，加上天气条件也不好，会出现发酵过度或者表面发霉的情况；2-也是基于1，果胶少了，豆子的干净度一致性就会有改善； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于Kaizen Farm ‍ ‍
庄园的故事始于一个共同的梦想，这是庄园主和妻子在七年的艰苦工作和不断储蓄中培育出来的愿景。 2018年，经过一番努力，这对夫妻终于拿到了土地。这是一片荒地，杂草丛生，但在他们看到的是：把它变成一块不仅可以种植咖啡的地方，而且可以成为他们的希望和奉献的地方的可能性。

2019年，他们满怀决心，开始种植。在地里的每一株植物都是他们迈向未来的一步，象征着家族的信念：从别人认为无用的东西中可以长出美丽的东西。这并不容易。他们面临挑战，考验着耐心和力量。然而，他们从来没有让困难浇灭对这个项目的热情。

如今，这片曾经的荒地为他们带来了收获和加工大量精品咖啡的乐趣。他们种植的每一粒谷物都承载着家族历史的一部分，证明了通过爱、辛勤工作和梦可以取得什么成就。
这段旅程并不轻松，但收获颇丰。他们全心全意地不断改进，不仅在咖啡的生产和收获方面，而且在发酵过程以及对环境和社区的贡献方面。他们的庄园不仅仅是一个工作场所；也是他们梦想的家园，是他们共同努力的一生的成果；
Kaizen -  意思是不断的进取改变，它代表着Julian和妻子一起日复一日年复一年的为了更好的生活和生产产更优质的咖啡的不断进取的精神和实务； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于本批次处理方式 ：
1- 鲜果采摘，浮选与人工分拣进一步筛除瑕疵果和杂质
2- 挑选后的鲜果放入塑料袋静置30小时 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
3- 脱皮，放入塑料袋中静置厌氧发酵30小时
4- 发酵结束后，用尽量少的水简单清洗
5- 晾晒12天左右，收袋静置
6- 静置15天左右抽样测试
