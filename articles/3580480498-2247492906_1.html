ToH - Taste Of Harvest
它的全称是 African Taste Of Coffee Competition，是由AFCA（African Fine Coffee Association翻成非洲精品咖啡协会可否）牵头，与非洲各个产国的咖啡协会/主管单位对接的一个，非洲咖啡产区的咖啡生豆的竞赛赛事，面向全非洲咖啡产区的生产者/贸易商提交生豆参赛，然后用SCA的评分系统来评选，目前参与的国家有埃塞，肯尼亚，乌干达，刚果金，坦桑尼亚，赞比亚，马拉维，喀麦隆；赛事的流程是每个国家先竞选，然后再全非洲再比，每个国家根据自己国内的产业情况有分不同的组别，比如说埃塞有日晒组，水洗组，蜜处理组，乌干达有日晒和水洗组，刚果金只有水洗组（感谢啡旗的朋友群里大家伙的解答） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

今年我们买到的批次是 埃塞国别的ToH#1 日晒，水洗和蜜处理 ； 这里面 日晒和蜜处理来自于Sidama下面的Bensa附近，水洗来自于Guji ，干净度，风味的辨识度/强度都非常高，代表了产区/品种/处理方式各个环节/方面的精致要求下的优质产品，因为每个豆子都有各自的文章详细介绍，这里就不赘述了～
除了ToH的3只外，我们还选到了两只常规渠道来的空运批次，一个是去年卖过的Rumudamo水洗，一个是去年接触到过，但没有机会购买，今年买到了的超级超级棒的Hamasho日晒，这两也都是Sidama区域的，超棒～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
注意：因为是空运批次，所以价格会贵一些；另外，ToH#1的日晒比水洗/蜜处理贵好多 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

肯尼亚 ‍
木哈哈，又买到了Ichamama，而且这回有日晒哦，还记得第一次喝到肯尼亚日晒还是2016年，张园店刚开张那阵子，从英国的Hasbean买到了我人生中的第一支肯尼亚，记得合作社好像是Othaya，后来好像每年都能看到肯尼亚的日晒，大部分也都是来自于这个合作社的，再到后来市场上出现了特别贵的肯尼亚的超级日晒（来自于Sasa的Project Origin项目），风味是有很顶的，但是价格对我们来说有点小贵，卖起来很吃力～今年，要特别感谢际遇的馨姐，居然找到了Ichamama的日晒，是Ichamama哦，是去年水洗里面风味强度我们用下来zui强的处理站，这回的水洗和日晒都很不错（虽然大货打样我还没有喝到，但据王老师反馈ok的）～

关于产季的一些交替 ‍ ‍
大家开始询问豆子时问说新产季的豆子有了没有，有哪些呀～这里小编还是需要说一下，所谓的新产季看具体的产国和处理产品，有不同的空运/海运到港的月份，不是一下子全都来的节奏；每年翻过年后，非洲区的埃塞和肯尼亚会先到，有时候春节前后，有时候会晚一点到3/4月～随后就是中美洲，比如说巴拿马，哥斯达黎加，危地马拉，洪都拉斯等，还有非洲的卢旺达和我们的云南产区会介于埃塞肯尼亚和中南美洲间有新产季的产品上市～然后一直到国庆前后都一直有非洲和中南美洲的豆子陆续到（不同批次，不同渠道来源，不同的缘由导致的发运/采购延期等等）～特别的，需要提一下，哥伦是全年都有产出的，夸张一点说，每个月都可以有新产季新批次的豆子，现在有一些生豆渠道的朋友开始按照季度来细分了，比如说Q1/Q2/Q3/Q4～巴西，印尼和巴布亚新几内亚差不多是在中美洲之后陆续上市，大概这样一个交替的节奏； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

有新产季的豆子上市，不代表前一个产季的豆子就不行了～新产季的豆子也不一定就干的过旧产季的，新旧产季和好坏没有直接的关联，还是要以喝到的为准 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
