Guava, Tangerine, Honey Pomelo tea-like
时隔两年，再次拿到了Shakisso的厌氧日晒批次，依旧是那个味道，不是很重的厌氧感，发酵带来了比传统日晒更为复杂的果味，像热带水果类型的菠萝番石榴，但依旧有品种本身的清新柑橘特质保留了一些，如果拿来做意式甚至会出现类似蔓越莓干蓝莓干的果香和酸感，做手冲酸感会下降一个强度，就会更偏柑橘一些，挺好的～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于这三个当地品种：（节选自朗巴赫公众号） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
Kurume: 树形较矮小，果实较小，产量较低，但风味强度很高，以柑橘、花香、茶感著称； ‍ ‍ ‍ ‍ ‍
Dega：生长在较高海拔，耐寒能力强，酸质活跃； ‍ ‍ ‍ ‍ ‍
Wolisho：树形较高，果实较大，产量较高，具有复杂的水果风味；

关于Guji产区
Guji位于埃塞的Oromia洲，其首府是Awasa，在很早期的埃塞行政划分里是属于Sidamo省，与埃塞咖啡另外驰名的Yigracheffe耶加雪菲同属于南部部族州SNNPR，后来埃塞行政划分重新规划后，原来的Sidamo省被拆分，少部分继续留在了SNNPR，大部分被拆分出去到Oromia州，其中就包括了Guji区域。

Guji区域一直也出产非常高品种的豆子，在2015年，埃塞的商品交易中心ECX，将精品咖啡等级下的品项中，Guji被单独划分出来，作为产品品牌标识一样，与耶加雪菲并列在ECX的出口分级列表里。
