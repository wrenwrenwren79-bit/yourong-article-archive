基本资料
庄园主/种植者： Andres Quiceno
庄园： 米兰庄园 El Milan
海拔高度：1400 米 masl
产区： 里萨拉尔达-佩雷拉 Risaralda- Pereira
品种：卡斯蒂优 Castillo
产品系列：Captain Mark
处理方式：威士忌酒桶厌氧蜜处理 Whisky Barreled Anaerobic Honey ‍ ‍ ‍
烘焙度：浅度 Light Roasted
风味：香草、洋甘菊、黄柠檬、蔓越莓、蜂蜜柚子茶
Vanilla, Chamomile, Lemon, Cranberry, Honey pomelo tea-like ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
这个产品是第三年测到了，之前没有选用是因为酒桶的风味太浓郁了，特别奶油香草，有点过于抢眼，虽然也能感受到咖啡的酸甜苦；今年的这个批次是无意中再次测样，想着我们有云南的葡萄酒桶，波本桶的桶内陈放发酵处理，可以和米兰的做个组合对照，测了发现wow开始喜欢它的美丽，上个月Andres来上海也和他一起测了Captain Mark，才知道去年底开始他开始调整这个产品的处理过程，也是希望它的香气和味道能更和谐，很棒！
它入口是很奇妙的香草和洋甘菊组合，香气过后是很舒服的柠檬+红布林蔓越莓的果酸然后尾韵也有柚子茶和柠檬红茶的感觉 ，第二口大口喝时尾韵还会出来一个树莓的香气，好喝，好特别～


关于Milan庄园

// 文字来源于Amativo公众号

Milán农场，位于哥伦比亚Risaralda Pereira里萨拉尔达佩雷拉 ，种植面积200公顷。种植的品种有：
Gesha 、Red Bourbon 、Yellow Bourbon 、Pink bourbon、Bourbon Tekisic 、Bourbon Sidra 、Striped Bourbon、 Tabi、Java 、SL 28 、 Catiope 、Sudan Rumé、Moka 、Laurina 、 Yirgacheffe 、Maragogype 、 Caturra 、 Purple caturra 、 Castillo 、Colombia。
由于气候变化，这个地区的咖啡生产变得非常困难，昆虫的繁殖，丰收时又缺工人。目前，生产商的处境都非常艰难，但我们一直在创新，寻找研发更好的加工方式来满足市场需求。因为我们不能失去作为咖啡生产商的核心。我会用我的一生，一直在这里继续咖啡种植和生产。
Milan与小溪 La Riviera属于一个公司旗下，他们还有一个烘焙品牌叫做Cafe Uba，办公室和烘焙工厂位于佩雷拉市区。

这里会发展成一个集合的加工处理中心
现在这里只能进行湿处理，而干处理是在不同的地方进行的，我们规划6个月后，开始解决这个问题。
做了一些定制（开孔）的威士忌酒桶 ‍ ‍ ‍ ‍ ‍ ‍
为了保证风味的一致性和强度的浸渍养护的橡木片，发酵时橡木片也是放在桶内的 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
用来搅拌均质的机械装置 ‍ ‍ ‍ ‍ ‍ ‍

‍ ‍
关于本批次处理过程（分系列介绍）：
  1. 手选采摘成熟的咖啡果 ‍ ‍
  2. 清洗咖啡果并再次手选
  3. 将咖啡果进行有氧发酵
  4. 去除部分果胶
  5. 放入曾经用来陈酿威士忌的橡木桶
  6. 并加入酵母进行发酵
  7. 完成后移至晒棚干燥至含水率达到11%
