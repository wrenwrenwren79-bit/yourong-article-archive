// 分区域 ‍ ‍ ‍

Sidama大州，我们刚接触咖啡时，那个时候流传的西达摩省是更早期埃塞行政划分以及咖啡出口的合同中咖啡品类的规定，近些年随着Bensa，Bura，Arbegona这些小区域的产品出现越来越多，也让大家对Sidama有了更多的认识; ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Yirgacheffe，耶加雪菲，这是多少人曾经现在以及未来的白月光呀～每个人是不是都有它记忆中最美好的那杯耶加～根据2022年ECX埃塞商品交易中心发布的合同约定，对于耶加雪菲的分类定义将耶加雪菲小镇周边的几个区域都囊括了进来～Wenago, Kochere, Gelana Abaya和Dilla Zuria; ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Guji, 曾经它是被“雪藏”在Sidama分类下的，一直到2015年埃塞商品交易中心才将其从单独拎出来作为一个类别；印象中，我们国内市场也是在按个时间点之后几年陆续开始出现一些Guji名字的豆子； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

我的白月光之一Nensebo所从属的区域 - West Arsi 阿肆西部 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Bench Maji，现在改名叫做Bench Sheko；与Keffa相邻，我们每年都会买的Kamarch Gesha Farm就位于这个区域，著名的Gesha Village也在这个区域； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Djimma, 这个区域的豆子我们拿到的不多，每年都会买的Gera以及偶尔会买到的Limu来自这个区域； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
