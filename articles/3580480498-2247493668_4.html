Santos是我们第一次选到，反复测了几次它的表现越来越惊艳，就好像一个花朵从刚花苞打开到完全绽放的过程变化一样；查资料才知道原来Santos是非常早期，可能是最早的一个（一批）农场和Lost Origin做实验批次的，那个时候其实Lost Origin的处理厂甚至这个项目都还没有成立，当时最初的实验可能是从Pacamara品种开始尝试的，然后到瑰夏； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

这个批次在农场是代号G10系列下的Lot5小批次，第一次喝的时候是我烘焙的样本，觉得它是好喝的但第一感受就是觉得很像之前的艾力达的Loma或者Torre的厌氧日晒，能感受到莓果的主调性和饱满的酸质，触感甜感也都挺好的；当时没有感受到那种要买的程度，然后同时还收到了生豆商朋友烘焙的熟豆样本，再次测试发现我勒个去，有点厉害哦～买！ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

处理过程：
鲜果采收筛选后，放入发酵罐，添加Kveik Voss酵母和乳酸菌，控制温度环境下厌氧发酵10天，发酵结束后取出转移到暗房中晒床干燥35天；


关于Santos Cafe

1947年，Don Ismael Lezcano 抵达奇里基省的圣克拉拉；在他 18 个孩子的帮助下，他们开发了一个种植豆类、咖啡、甘蔗、玉米和牛的农场；而我们的主人公Don Santos Lezcano就是18个孩子之一，第二代咖农，开创了现在的桑托斯庄园，到现在Lezcano家族已经是第五代了；

Don Santos，第二代咖农，农场的老法师，2021年91岁时的照片

桑托斯庄园总占地 55 公顷，有两个农场Finca Bartolo和La Mimada用来种植不同的品种；Bartolo种植卡杜拉 (Caturra) 和卡图艾 (Catuai) ，面向大宗基础用豆，最开始是面向巴拿马本地市场的咖啡需求的，也是家族从Santos老爷爷时代就开始种植的地方，海拔相对低一些，介于1100-1400米；La Mimada是更高海拔，家族后期购入的用于种植更好的一些精品品种，面向精品市场需求的，目前有种植卡杜拉，Pacamara，黄波旁和瑰夏，并且大部分的实验方式/批次都是来自于Mimada；
