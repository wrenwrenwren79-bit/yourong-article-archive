Pomelo, Raspberry, Cranberry, Blue berry ‍ ‍ ‍

这是王老师1月份去埃塞选的豆子，是一个首次接触的出口商和咖农，与ALO的Tamiru和Karamo的Niguse一样的发展轨迹，Mulugeta Muntasha也是一个很有商业（精品）意识的咖农，从CoE崭露头角后创立了Bursa公司生产高品质的区域小微批次；你可以从google上搜索到很多国外的精品烘焙厂牌这几年采购售卖Muntasha的豆子，也可以从Bursa Coffee的官网看到很有准备的一个专业网站； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
说会这两只豆子，两只都是做了一些厌氧发酵处理的，但是发酵感并不重，日晒的批次会更像成熟的果感，有果肉感，成熟水果到热带水果的果香，但又不是番石榴那种，是更讨喜更甜美的百香果，菠萝，芒果枇杷这些参杂在一起，大口大口地喝很满足～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
蜜处理这只就非常的细腻，那种一入口就觉得哇塞，这个酸质太舒适了，高温有具象的蜜柚、树莓的果香再到蔓越莓，特别像那种坚果零食包里的蔓越莓果干和蓝莓果干，我个人会更偏向蜜处理，但相比日晒就是触感会轻薄一些些； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
两只都超棒～都是空运批次，价格有一丢丢小贵！ ‍ ‍ ‍ ‍ ‍ ‍

关于Mulugeta Muntasha ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
Mulugeta Muntasha从事咖啡也有超过15个年头了，2021年回归到他的故乡Bursa村，建立了处理站，同年来自他处理站和他的妹夫的咖啡分别获得了埃塞当年CoE的第2/6/15名；2022年，又获得了埃塞CoE的第1/4/6/8名；2024年的第3名，这些战绩都彰显了他所能选到的鲜果质量以及加工处理出来的成品的品质； ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
