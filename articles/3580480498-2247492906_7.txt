// 首先我们来串联一下历史故事线
在巴布亚新几内亚东部高地的
艾尤拉山谷里有一条河流叫做
Lamari
，传说Lamari河流中间有一块巨石，
石头里有一个精灵守护着附近村落，它的名字叫做
Baroida
。
1962年来自澳洲的Ben Colbran花费了所有积蓄（900澳刀）从当时的原住民Taro手里买下一块65英亩（约27公顷）土地
，与他一起开垦这块土地，最初是种植一些蔬菜，卖到附近城市LAE的市集，当时价格还不错。
1963年初，政府鼓励大家开垦土地种植咖啡，也开启了Baroida庄园种植咖啡的历史。
1979年，由于政局因素，Baroida被迫卖给了当地一个信托机构，Ben的长子Nichol非常的心痛也无法割舍，他决定积蓄留在Baroida担任经理来管理庄园，干了13年后，Nicole转到西部高地区域承接了一个旧的咖啡庄园.
1997年，Ben将Baroida买回，庄园内的咖啡树已经成杂草丛生，Ben不得不重建了整个庄园的咖啡种植;后来Ben与妻子和两个女儿都回到了澳洲生活，长子Nichol继续留在Baroida打理，就像LAMARI的那块精灵石一样，他稳稳的扎根在那里，继续经营着家族的咖啡庄园，也给当地居民带来了稳定的经济保障。
Baroida出产的咖啡一直都是精品等级，美国的反文化Counter Culture, 星巴克甄选Starbucks Reserve，澳洲的精品连锁巨头Campos都通过直接贸易与Baroida采购。
// Baroida 庄园豆
Colbran家族自己庄园种植，处理的产品有Baroida 水洗/蜜处理/日晒，Morita单一品种水洗处理和今年第二年产出的Gesha水洗处理；其中Baroida水洗是我们在Olive以及一些特定的浅焙拼配使用的基础豆；
Morita 单一品种区块种植
2019年，反文化将Colbran家族提交的Arusha品种送交世界咖啡基因检测中心进行检测，结果证实Arusha与K7（源于印度的Kent后在肯尼亚推广种植）基因一致吻合，这也解释了这么多年来大家从PNG的豆子中喝到似肯尼亚的红色深色莓果调性。Morita是在Baroida庄园内单独辟出一个区块，海拔相较高出其它种植区域100-200米，仅种植Arusha这一品种；目前没有在售批次；
// Lamari 村落小农
在Baroida庄园附近有几个原住民村落，以Lamari河流命名的Lamari村落便是之一，从最初Ben Colbran开始种植咖啡时，Lamari村落的原住民们别被雇佣来做工搭建设施，产季是采收处理咖啡；村民们看到了咖啡种植的商机，便有意识的偷偷带一些咖啡果回家，种植在自己家的农田里；慢慢的村落里家家户户都有了咖啡种植，也都随着与Baroida成长为咖啡种植的老司机，再后来，Baroida便每年产季时从Lamari村落农户手里买干燥好的带壳豆，再脱壳处理，以Lamari的名字作为品牌售卖出口，也正是这样的贸易方式来永续着村落里农户的家庭生计；

// Kobuta 村落小农
这是一款来自于Kobuta村的农户集体生产的咖啡，由Colbran家族的处理厂进行处理，保留Kobuta名字作为品牌出口，反文化从2015年开始直接贸易采购；四只咖啡里它是被很多烘焙者喜爱的一只，风味很细腻；

// Tairora 村落小农
与Lamari和Kobuta相似，Tairora也是村落小农种植，采收后将鲜果或者干燥好的带壳豆卖给Baroida庄园来进行后续的加工，最后脱壳后售卖到国际市场。反文化在早些年曾经连续采买过这个产品，但是中途由于村落的消失导致无法稳定出产咖啡，现在也是不一定每年都有，但凡有它，我们都会用来出单品和与Baroida水洗搭配着用在一些偏浅焙对干净度和风味层次有要求的浅焙拼配里做基础部分；目前没有在售；

// Boka 单一小农家庭
Boka是从Kobuta村中脱颖而出的一个单一小农批次，因为农户叫Boka，所以冠名作为产品品牌出口，也是反文化2015年的采购中发现并推到市场的，是我一直非常喜欢的一只，没办法，看到SINGLE FARMER LOT就无法自拔；曾经有水洗和日晒，目前还没有新的批次在售；
