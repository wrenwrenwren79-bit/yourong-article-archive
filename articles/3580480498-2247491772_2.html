就在上月开始策划秋季拼配时，我们想做两个不同色彩的版本来代表“金秋”和“深秋”于是朝着黄色水果和深色水果的调性去琢磨，测到第二个版本的深秋时，我记得那天韩啸帮我做的那杯入口超级的丝滑，一下子柑橘莓果酸甜所有的我记忆中的一杯好咖啡的特征全部暴击我，如果那个时候能有表情包的话我希望是那种游戏里面连招或者x1x2x3x4x5最后Super一下子的那种效果，所以我就改主意了，这个豆子不能只出现这么的短暂的时间窗口，要做一个常年都可以喝到的版本，晚上回来我想了想，隔天就跟老王说我们做一个新的常规拼配 Smooth waves。 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
组成的基本思路：
  • 埃塞 水洗 G2 （基础）
  • 云南 蔓飞龙 SDH （厌氧蜜处理，用了少量的佛手水果浸渍+LALLEMAND的红酒酵母，很柑橘，酸甜感也很不错） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
  • 哥伦 Java 水洗（柑橘，莓果） ‍ ‍ ‍ ‍ ‍ ‍ ‍
  • 哥伦 粉波 日晒 （红色莓果，核果）
  • 哥伦 卡杜拉 厌氧日晒（定向菌种发酵，红色莓果） ‍ ‍ ‍
  • 危地马拉 帕卡马拉 水洗/日晒 （它可以提供很不错的红色深色莓果调性） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

风味特征：柑橘、莓果、柔软俺的顺滑 ‍ ‍
Citrus, Berries, Soft and smooth ‍
