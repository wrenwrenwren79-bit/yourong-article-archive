Primitivo的风味跟卡杜龙非常像，第一口喝下去或者说在杯测盲测，我觉得很多人都会把他们两归位一类或者一个豆子，可能烘焙度不同带来的香气酸感差异；就我们当前这两个批次来说，Primitivo的发酵感更重，从生豆上就能看出来，但我们不希望开发太多的发酵感，所以烘焙上会做一些调整，它整体的酸质感觉比卡杜龙更有层次一些？或者发酵感多一些带来的更偏酒感/可可/酒心巧克力的特征～它入口的人参果感受比卡杜龙更明显冲击力更强，所以我就把它排在了前面～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
它入口是很直给的人参果和黄苹果复合蜜瓜的甜香气，就是这几个水果一起给你一拳的感觉，然后中后段会转一个很舒服的酒心巧克力的感觉出来～好有意思的一款豆子 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

品种：黄瑰夏 Yellow Gesha

处理方式：厌氧日晒 Anaerobic Natural
风味：柑橘、 黄苹果、 哈密瓜、刺梨果
Citrus, Yellow apple, Rock melon,  Rosa Roxburghii fruit
黄瑰夏这款入口虽然没有巴拿马瑰夏或者危地马拉绝色瑰夏那么的辨识度很强的花香，但它依然直给了你一个黄色水果复合着一些花香的调调，入口就是很饱满的柑橘类水果的酸甜感，中后段出现了刺梨果果汁的那种香气 ～ 妈呀，学了一个新的单词，刺梨果，好复杂，最近陆续到了几个黄色果皮的品种，我发现他们有一些相似的风味，比如都有黄色水果的香气，黄苹果呀，人参果呀，蜜瓜之类的甜香，不确定是不是因为黄色果皮的特殊性，另外他们也都有不同程度的刺梨果和菇娘果的香气，连口感咬下去的那种果肉果汁一起的感觉也很像，挺有意思～ 最新更新2024.4.19，今晚的黄瑰夏超级的白桃乌龙茶，好奇妙哦～不知道是昙花一现还是变调了jajaja ‍ ‍ ‍ ‍ ‍

同时到了两个黄瑰夏的日晒，一个来自于巴西的达特拉，一个来自于哥伦比亚的贝图里亚，从香气丰富性上，贝图里亚的完胜，辨识度更强，但贝图里亚的会有发酵感，达特拉的会比较传统柔软；贝图里亚的Primitivo(Primitive)是庄园自有品种，是Luisa发现的庄园里的一个黄皮果子树根周边的树都不太一样，就把它当宝贝的单独去育种繁殖种植开来，我感觉它的风味特征特别像卡杜龙，最近我们在云南澜沧做了一些萨奇姆的实验处理，发现萨奇姆也能出先这种黄色水果/蜜瓜类的风味，所以我又在琢磨，会不会卡杜龙呀，Primitivo呀其实和萨奇姆有血缘呀～神奇的自然 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

这是我们时隔两年后再次买到贝图里亚的豆子，也是这回去哥伦亲自有机会去拜访的咖农，去之前以为会不会不是一个人，多方打听了解到，Luis是一个很神奇的咖农，他对于咖啡品种特别着迷，他真的是特别特别的喜欢咖啡，每天都会去地里看看，每次看到有一些蛛丝马迹是不同的一些特征，他都会特别留意，也真是这份认真和真挚的喜欢，他可以照料着20多个品种，地里打理的特别的有条理，很干净整洁的田间，还有自己庄园独有的变异品种，而这只卡杜龙日晒也是目前我们测到的风味强度zui高的一只，卡杜龙独特的蜜瓜，黄色水果的香气特别有，特别像云南的人参果一口咬下去的香气，甚至那种果汁感都像～推荐！！！最新到的Primitivo和黄瑰夏都是俺去年去产区时在农场里测到就拍板下单买的～非常特别的三款豆豆，不同的品种，但有相似的香气特征，而且这些香气特征全部并非来源于处理哦，都是豆种自带的buff～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


关于 Villa Betulia 和 Luis Anibal Calderón

路易斯先生是第二代咖农，从12岁起就跟着父亲在咖啡地头农作，15岁时，父亲给了他小块地，从此Luis每年都可以从这块地获得一些额外的收益，经过多年的奋斗，2005年Luis在Acevedo买下一块20公顷的土地，建立了Betulia庄园；2012年是Luis的一个转折点，在这之前，他一直挣扎在之前的错误投资带来的经济负担中，2012年，Luis尝试种植了5000株瑰夏，占当时总种植5%，其余的都是Castillo和Caturra，2015年，这些瑰夏开始有产出产生经济回报，由于相比传统品种和传统的商业采购，瑰夏能有更高的溢价，也使得Luis从此认定了种植稀有和高净值的品种才是一个好的出路，随后他种植了很多市面上罕见的品种，像粉波旁，条纹波旁，尖身波旁，粉红瑰夏，矮树种瑰夏，Sidra，Wushwush，Java， Papayo，玛拉瑰夏以及庄园独有的品种Primtivo（黄果皮的）。 ‍ ‍ ‍ ‍ ‍ ‍ ‍
