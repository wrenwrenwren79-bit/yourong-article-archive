这个产品是我们第一款单一庄园的多品种、多处理方式的手冲拼配，它出现的动机是我们能从渠道拿到更多多样的豆子，有机会做一些组合/融合的尝试；他们有传统处理的Java水洗和Gesha乳酸菌厌氧水洗，有天然低因处理的红波旁，也有用酵母做的微生物发酵的Chiroso厌氧日晒，辣椒波旁厌氧水洗以及一款最近才进入我们视眼的新品种“大肚脐” Ombligon；这个产品不是为了溯源而生的，它的目标只有一个就是让大家喝到一款风味香气辨识度强，咖啡品种自身的味道（酸质）和触感都能非常完整的呈现出来，就好像咖啡师比赛的第三杯饮品 Signature Drink一样，我们会用每一季度/产季精选的Diviso来融入其中，来同步呈现产区的面貌，强烈推荐～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍


关于El Diviso
El Diviso位于慧兰的Pitalito镇，庄园的主人Jose Uribe Lasso为了远离暴力的生活环境，从娜玲珑搬到了Pitalito，于2000年初购得了El Diviso，开始新的生活篇章。
选择慧兰，是因为肥沃的土壤与健康多样的生态环境，给了Jose信心，只要努力，种咖啡或者其它任何作物都可以很好的生活下去。

Jose将庄园分割了不同的地块分别给它的3个儿子，让他们选择想种的咖啡品种，鼓励他们自己选择合适的处理加工方式，现在庄园里有种植的品种有瑰夏，爪哇，卡杜拉，粉波旁以及一种叫Bourbon Aji的波旁品种。


关于Diviso的处理方式 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

从很多的途径获得的信息，我们总结下来它的处理方式有这些环节/点， ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

  • 制作专用的发酵助剂/发酵液，其中有定向分离培养的菌种，以及咖啡果自身的发酵液

  • 鲜果的预发酵（有氧/厌氧或者组合形式）

  • 鲜果去皮后与发酵液的浸渍（厌氧/有氧或者组合形式）

  • 温度冲击（冷/热冲击）

  • 干燥（遮荫/机械）以及干燥分多阶段来调整发酵
