烘焙度：浅焙 Light Roasted


品种： 瑰夏 Gesha

处理方式：日晒 Natural ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

建议养豆：2周 ‍ ‍ ‍ ‍

风味：树莓、蔓越莓、葡萄柚、红色花香、深色葡萄 ‍ ‍ ‍ ‍

Raspberry, Cranberry, Grapefruit, Red flowers, Dark grape

这款日晒与去年的日晒有不同，去年的比较偏向莓果转核果，今年的日晒就纯纯的莓果调，复合着柑橘和花香，有几次冲出来是很直给的树莓，越喝越喜欢于是虽然它价格小贵一点，但还是补了几箱想多卖一阵子～大家喝喝看感受一哈 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

品种：希爪 Sidra

处理方式：水洗 Washed

建议养豆：2周

风味：洛神花、葡萄柚、蔓越莓、红布林、水果硬糖

Hisbiscus flowers, Grapefruit, Cranberry, Red plum, Fruit drops

这只Sidra水洗喝起来超级瑰夏的感觉，入口是很舒服的柑橘+红色莓果/核果复合的果酸，同时还有像泡的洛神花茶的酸香，尾韵会有一丝水果硬糖的糖果甜感，很有意思的一只豆子，特别有层次耐喝～ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

品种：曼德拉 Mandela

处理方式：168小时厌氧日晒 168H Anaerobic Natural

建议养豆：3周

风味：蔓越莓、树莓、葡萄柚、可可碎、红酒感 ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

Cranberry, Raspeberry, Grapefruit, Cacao nibs, Winy ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍
曼德拉是一个多阶段杂交的品种，分别是卡杜拉，Timor和埃塞原生种；官网描述的过程是先从卡杜拉品系里筛选出特征最优的卡杜拉，然后再和Timor杂交后选育筛选出特征稳定的再与埃塞原生种杂交，它也有绿顶和红顶两种树形；这一个批次是发酵比较多的批次，入口的感受和90+的展望很相似，热带水果+红色莓果+可可和红酒感的复合体，酸度中等偏高，果汁感和甜感很饱满，是一款很有记忆点的豆子～也是我们对这个品种的初体验；（下面是官网的风味特征参考截屏） ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍ ‍

关于 希望庄园（Café Granja La Esperanza）
布兰卡· 里格加·科瑞（Blanca ligia correa）和胡安·安东尼奥·海瑞拉（juan antonio herrera）结婚，养育了14个孩子。这对夫妇后来被分配到波斯特西农场（postosi farm）工作，在此定居下来。1945年，除种植铁皮卡（Typica）以外，胡安·安东尼奥决定引入黄波旁（Yellow Bourbon）、红波旁（Red Bourbon）和卡杜拉（Caturra）等三个品种的咖啡。于是，1945年，希望庄园就此诞生；现在整个希望农场除了最初的几个传统品种外，还有瑰夏、希爪和庄园自己筛选和变异的品种种植； ‍ ‍ ‍ ‍

希望庄园旗下有5个农场，分别 是

  • Hawaii ， 位于 Cundinamarca- Sasaima

  • Potosi，位于Cauca- Caicedonia

  • La Esperanza ， 位于Cauca- Trujillo

  • Las Margaritas，位于 Cauca- Caicedonia

  • Cerro Azul， 位于Cauca- Trujillo
