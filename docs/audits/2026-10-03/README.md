# 有容乃大文章归档复检报告

复检日期：2026 年 10 月 3 日。对象：现有原文归档、同一批 WeRSS 的 content 与 content_html、GitHub 导出目录、图片文件。此次未在线逐篇核对公众号原文，也未核齐最新目录；此前站点安全策略阻止访问原文页，本次没有改用其他途径绕过。

**结论：用户对不完整的疑问有依据。既有“正文已恢复”和图片哈希通过，不能证明原文完整。此次发现提取边界遗漏，同时确认图片文字、封面和未取得正文等缺口。**

## 确认的缺口

1. **图片文字未进入 TXT。** 90 篇标记 body_recovered 的记录，有效文字不足 100 个字符；其中 2 篇是零字但有图片。90 是复核队列规模，不表示全部都是异常短文。以《我想知道谁会买这78只豆子》为例，TXT 只有“购买链接👉”，清单内容保留在原图中。水质文章中的转换系数也在图片里。
2. **封面未单独纳入离线归档。** 对 1,270 条 pic_url 与正文图片清单进行对比，1,262 篇的封面没有匹配的图片资源路径，共涉及 939 个不同路径。路径匹配忽略域名、末尾尺寸及查询参数，是排查线索，不是下载后的二进制去重结论。封面可能承载有效信息，例如文章自己提到更换为品种研发时间轴的封面。
3. **4 篇存在正文容器外的漏提文字。** 一篇视频类文章漏了 127 字说明；两篇 FNC 转载各漏了 138 字来源与账号介绍；一篇开业转载漏了 156 字编者荐语及来源介绍。这些不全是正文段落，但完整原文归档应保留其位置和角色。已保存到 supplemental_content.json，旧归档未静默改写。
4. **CSS 图片遗漏。** 《No underwater hockey no coffee》有 3 个背景或边框图片地址不在 image_urls 清单中。根据样式检查主要是布局装饰；其他已存在资源的远程 CSS 引用也未本地化，离线版不能保证完全还原原版布局。
5. **已有正文缺口仍存在。** 旧状态为 7 篇无缓存、3 篇缓存无有效正文、3 篇图片消息不完整。本次从其中一篇恢复了说明文字，但视频未归档，不能因此宣布整篇完整。重要缺失包括《【咖啡产区系列NO.1】关于埃塞俄比亚（干货收藏贴）》和《2026产区行～走到哪写到哪～第1天和第2天》。
6. **媒体和目录范围尚未补齐。** 49 篇仍含未离线保存的音视频或嵌入媒体；第 56、57 期及最新文章覆盖未核齐。数据库现有 1,270 行与索引一致，不是独立的完整目录核验。

第二份 content_html 缓存普遍比正文长，主要因为夹带封面、预览提示、授权弹窗、点赞分享按钮和二维码。此次对这些进行区分，没有把界面文字拼回原文冒充“补全”。

## 文件与处理状态

- `audit.json`：1,270 篇逐篇检查明细与统计。
- `review_queue.csv`：短文、已知缺口、漏提文字及 CSS 图片复核队列。
- `supplemental_content.json`：4 篇新检出的文字、来源定位和原缓存哈希。
- `cover_assets_pending.json`：未匹配现有图片路径的封面关联清单。
- `samples.html`：8 个对照样本，图片已内嵌，断网也可查看。

本次完成复检并保存补充证据；没有全量 OCR、补抓封面或媒体，也未覆盖旧 Release 的原始快照。2026-10-02 阅读包仍是复检前版本。下一次修订应在新版本中合入补充块、建立封面和背景资产角色、按需 OCR 并保留图片定位，再按单篇文字、图片、媒体和目录四个维度报告完整度。

原脚本只优先取 #js_content，导致外围的编者荐语、转载来源及特殊类型说明可能遗漏。图片下载器只消费已经列出的 image_urls，因此后续文件哈希校验无法发现未被提取的图片地址。这是本次确认的流程缺口。
